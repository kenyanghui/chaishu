# 如何掌控自己的愤怒 · 教练技能

基于 乔·欧文《成长型思维》的教练技能。
拆书家：沐鱼



## 核心方法论

### What — 这是什么

**如何掌控自己的愤怒** 是关于「如何掌控自己的愤怒」的实用技能。情绪本身不是问题，被情绪驱动的自动反应才是。核心是"在刺激与回应之间，给自己留一个选择的空间"。

### Why — 为什么重要

研究表明，人的决策和行为70%以上受情绪驱动而非理性分析。情绪管理不是压抑情绪，而是建立"觉察→暂停→选择"的反射弧，让理智脑在关键时刻夺回控制权。
### How — 操作步骤

  1. **觉察情绪**：识别并命名当前的情绪状态（愤怒/焦虑/沮丧等）
2. **暂停反应**：在情绪冲动和行动之间插入"暂停"空间
3. **分析触发**：探索情绪背后的真实需求和触发因素
4. **选择回应**：基于理性而非冲动，选择建设性的应对方式
### Where — 适用场景

「如何掌控自己的愤怒」属于 **情绪管理** 领域的核心技能。

**跨领域连接：**情绪管理能力需要与以下领域协同发展：
沟通与表达(表达情绪)、认知思维(理解情绪来源)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「如何掌控自己的愤怒」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「如何掌控自己的愤怒」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（情绪管理方向）：**

A. **工作压力大** — 回想一个你最近遇到的工作压力大场景，用今天学到的「如何掌控自己的愤怒」方法重新思考如何应对

B. **人际冲突** — 回想一个你最近遇到的人际冲突场景，用今天学到的「如何掌控自己的愤怒」方法重新思考如何应对

C. **挫败感** — 回想一个你最近遇到的挫败感场景，用今天学到的「如何掌控自己的愤怒」方法重新思考如何应对

D. **失控时刻** — 回想一个你最近遇到的失控时刻场景，用今天学到的「如何掌控自己的愤怒」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「如何掌控自己的愤怒」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「如何掌控自己的愤怒」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「如何掌控自己的愤怒」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「如何掌控自己的愤怒」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
