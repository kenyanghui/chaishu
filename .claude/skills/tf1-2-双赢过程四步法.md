## 核心方法论

### What — 这是什么

很多人认为在沟通或谈判中，不是你输便是我赢，非要争个高下，让对方服从自己，然而，这种非赢即输的思维并不能给我们带来一个双赢的结果。在沟通、合作的关系中，可以满足自己的需求，也顾虑到对方的需要，创造出能够让双方都获利双赢模式的方法，简单来说就是“大家都可以是赢家”。

### Why — 为什么重要

回想一下我们过去一定有这样的情况：因为意见分歧与同事、家人产生过矛盾，认为自己不被他人理解，也不认可对方的想法，还可能会与对方的关系产生负面影响。通常输/赢竞争得到的结果，如果不是一个良好的沟通，这样会导致对方会对结果不满意，可能会有不遵守结果，或是抱怨，不甘心的接受情况。这样合作无法长久，不利人际关系。如果与他们沟通时，能达到一个让大家都满意的双赢，即节约了时间也会增加彼此的感情或合作关系。

### How — 操作步骤

  1. 换位思考 : 用对方的角度理解对方的需要和想法。
  2. 理清问题 : 理性思维分析沟通后的核心诉求，找到当前最主要的关键问题或首要顾虑。
  3. 确定结果 : 平等对话坦诚沟通，确认双方都可以接受的结果。
  4. 解决方案: 找到可以实现结果的各种途径方法，给出最终双方满意的解决方案。

### Where — 适用场景

双赢过程四步法适用于工作、生活等需要沟通谈判，当双方意见不同，而又坚持自己的想法和意见的场景。值得注意的是，应用双赢过程四步法，双方需要以相互了解和相互信任为基础，通过平等对话来达成双赢结果。

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「双赢过程四步法」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 换位思考 : 用对方的角度理解对方的需要和想法。
  2. 理清问题 : 理性思维分析沟通后的核心诉求，找到当前最主要的关键问题或首要顾虑。
  3. 确定结果 : 平等对话坦诚沟通，确认双方都可以接受的结果。
  4. 解决方案: 找到可以实现结果的各种途径方法，给出最终双方满意的解决方案。

每一步让用户用自己的话复述，确认理解后再进入下一步。
