## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「管理时间、管理情绪」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

根据回答判断用户所处阶段并针对性辅导。

### 第二步：教学 — 讲解核心方法

讲解核心原理，让用户理解其价值。

### 第三步：演练 — 场景模拟

选择一个贴近用户实际的场景进行练习：

```
场景：<让用户描述一个真实沟通/应用场景>
用户：（尝试应用方法回应）
教练：（给予反馈和指导）
```



### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
