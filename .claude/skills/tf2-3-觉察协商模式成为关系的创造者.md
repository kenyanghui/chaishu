# 觉察协商模式：成为关系的创造者 · 教练技能

## 核心方法论

### What — 这是什么

**觉察协商模式：成为关系的创造者** 是关于「觉察协商模式：成为关系的创造者」的实用技能。核心原则是：沟通的效果取决于对方的接收，而非自己的表达。只有从对方的角度出发，选择合适的表达方式和内容，才能真正达成沟通目标。

### Why — 为什么重要

在工作和生活中，绝大多数误解和冲突都源于沟通不畅。掌握结构化沟通方法，可以将模糊的表达转化为清晰的信息传递，减少误会、提升效率、改善关系。拆书帮RIA便签法强调"拆为己用"，而沟通正是最需要"拆为己用"的领域。
### How — 操作步骤

  1. **观察场景**：识别当前沟通情境的类型（赞美/批评/谈判/反馈等），明确沟通目标
2. **选择策略**：根据场景选择合适的沟通方法和话术结构
3. **执行沟通**：按照方法步骤进行表达，注意语气和肢体语言
4. **确认效果**：观察对方反应，确认信息被准确接收，必要时调整策略
### Where — 适用场景

「觉察协商模式：成为关系的创造者」属于 **沟通与表达** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `tf2-3-责任型授权` — 责任型授权
- `tf2-1-要事第一` — 要事第一
- `tf1-1-移情聆听四步法` — 移情聆听四步法
- `tf1-2-双赢过程四步法` — 双赢过程四步法
- `tf2-1-抓要事` — 抓要事

建议将同书技能组合学习，形成系统化的 沟通与表达 能力框架。

**跨领域连接：**沟通与表达能力需要与以下领域协同发展：
情绪管理(处理沟通中的情绪)、认知思维(分析沟通对象的需求)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
