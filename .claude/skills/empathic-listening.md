# 移情聆听四步法 · 教练技能

基于史蒂芬·柯维《高效能人士的七个习惯》的教练技能。
拆书家：玥清（广州小蛮腰分舵 三级拆书家）

## 核心方法论

### What — 这是什么

移情聆听是以理解为目的的聆听，要求听者站在说话者的角度理解他们的思维方式和感受。不仅是听对方的词句，更要做到「耳到、眼到、心到」。与之相对的是「敷衍聆听」—— 表面在听，实际心不在焉、或急于评判、或只顾想着自己下一句说什么。

### Why — 为什么重要

| 场景 | 不用移情聆听的结果 | 用移情聆听的结果 |
|------|------------------|-----------------|
| 家庭 | 不重视家人感受，争吵不断 | 建立情感链接，化解矛盾 |
| 职场 | 受限于思维立场，协作不畅 | 构建良好的协作环境 |
| 谈判 | 陷入立场对立，两败俱伤 | 找到共赢方案 |

本质：移情聆听构建的是同理心沟通关系，能帮助他人疏导情绪、认清自己、勇于表达。正如约翰·麦克唐纳所说：「同理心建立在理解和尊重的基础上，是人际关系中不可或缺的一部分。」

### How — 四步法

```
第一步：复述语句       →  专心聆听，重复对方的话（耳到）
第二步：加入解释       →  用自己话表达左脑逻辑理解（脑到）
第三步：个人感觉       →  加上右脑体会对方情绪（心到）
第四步：带情解释       →  左右脑并用，带情感地解释（全到）
```

**示例对比（家庭对话）：**

| 错误回应（不用） | 正确回应（移情聆听） |
|----------------|-------------------|
| 子：「上学真是无聊透了！」 | 子：「上学真是无聊透了！」 |
| 父：「不着急，先别说这事，现在就睡觉！」（指令式） | 父：「你已受不了了，觉得上学太无聊。」（复述语句） |
| 父：「总是拖拖拉拉的，你不想上学也得去！」（评判式） | 父：「你不想上学了。」（加入解释） |
| —— 关上沟通心门 | 父：「你觉得很有挫折感。」（个人感觉） |
| | 父：「你对上学有很深的挫折感。」（带情解释） |

### Where — 适用场景

- 家人朋友抱怨倾诉时
- 同事有负面情绪或工作压力时
- 商业谈判陷入僵局时
- 任何对方情绪激动的沟通场景

**注意**：移情聆听不适用于需要快速给出指令的紧急场景，也不适合对方明确只需要信息而非情绪支持的场景。

## 教练流程

当用户需要练习移情聆听时，按以下流程引导：

### 第一步：诊断 — 找出用户的「聆听盲区」

引导用户回顾一次近期沟通冲突：

```
教练：「回忆最近一次沟通中，对方说话时你在做什么？
是在认真听，还是想自己接下来要说什么？」
用户：（描述）
教练：「对方说完后，你感觉他/她的情绪被理解了吗？」
用户：（描述）
```

根据用户回答，判断其所属阶段：

| 阶段 | 特征 | 教练重点 |
|------|------|---------|
| 第一阶段 | 根本没在听，心不在焉 | 唤醒聆听意识，认识到「听」不等于「在听」 |
| 第二阶段 | 在听但急于评判/建议 | 练习先复述、再解释，憋住不提建议 |
| 第三阶段 | 能复述但忽略了情绪 | 练习捕捉和命名对方情绪 |
| 第四阶段 | 能理解情绪但不会表达 | 练习「带情解释」的综合表达 |

### 第二步：教学 — 讲解四步法

用核心方法论中的四步法表格进行讲解。重点强调每一步要「做什么」和「避免什么」：

```
第一步【复述语句】— 重复对方关键词
  做：重复对方的核心话语
  避免：添油加醋或过早评判

第二步【加入解释】— 用自己的话理解
  做：用「你是说…」「你的意思是…」开头
  避免：跳过复述，直接到解释

第三步【个人感觉】— 说出对方情绪
  做：用「你觉得…」「你感到…」给情绪命名
  避免：忽略情绪，只讲道理

第四步【带情解释】— 情绪+理解一起表达
  做：「你对…感到很…」的句式
  避免：机械套用，失去真诚
```

### 第三步：演练 — 场景模拟

选择以下一个场景让用户练习：

**场景 A：职场冲突**
```
同事抱怨：「这个项目根本没法做！需求三天两头改，我白干了两周！」
```

**场景 B：亲子沟通**
```
孩子说：「我不想学钢琴了，每次练琴都好烦，别人都能出去玩就我不能。」
```

**场景 C：伴侣相处**
```
伴侣回到家叹气：「今天真是累死了，开会开了一天，说的话比一周都多。」
```

用户练习时，教练按四步法逐层引导用户回应，完成后给出反馈。

### 第四步：反馈 — 四维评估

从以下四个维度评估用户的回应：

| 维度 | 1分（需改进） | 3分（良好） | 5分（优秀） |
|------|-------------|-----------|-----------|
| 复述准确度 | 完全没复述 | 复述了关键内容 | 精准复述核心信息 |
| 解释深度 | 照搬原话 | 用自己的话表达了 | 能点出对方没说出的逻辑 |
| 情绪捕捉 | 忽略情绪 | 说对了一种情绪 | 准确命名多种情绪 |
| 表达温度 | 机械生硬 | 语气温和 | 让对方感到被真正理解 |

## 练习题库

### 基础练习：四步拆解

给出一个场景，引导用户按四步法逐层写出回应。

**场景**：朋友说「我最近好焦虑，工作做不完，老板还在不断加活。」

```
第一步（复述）：________________________________
第二步（解释）：________________________________
第三步（感觉）：________________________________
第四步（带情解释）：____________________________
```

**参考答案**：
- 复述：「你最近工作做不完，老板还在加新任务。」
- 解释：「你感觉工作量超出了你能承受的范围。」
- 感觉：「你觉得很焦虑、很有压力。」
- 带情解释：「你对工作量持续增加感到非常焦虑和无力。」

### 进阶练习：现场反应

教练扮演倾诉者，用户即兴回应。教练按以下脚本模拟：

```
倾诉者：「我真的受不了我那个搭档了，每次开会他都抢我的话，
好像就他一个人有想法似的。我今天准备了一个方案，被他三句话
就带偏了方向，到最后完全变成他的方案了。」
```

用户需在 30 秒内做出回应。教练按下表评分。

### 高阶练习：真实场景复盘

引导用户回忆自己真实生活中的一次沟通冲突，用四步法重新演绎：

```
1. 当时对方说了什么？（提取原话）
2. 如果用『复述语句』怎么说？
3. 对方当时的情绪可能是什么？
4. 综合起来完整的『带情解释』回应是什么？
```

## 常见障碍与应对

| 障碍 | 表现 | 教练应对 |
|------|------|---------|
| 「我明明在听啊」 | 不认为自己需要练习 | 播放一份录音/聊天记录，让用户复述对方说了什么 |
| 「这样说话好假」 | 觉得四步法太刻意 | 解释这是「有意识的练习」，熟练后会内化为自然反应 |
| 「我忍不住给建议」 | 听完就想解决问题 | 练习「憋住30秒」，先复述再确认对方是否需要建议 |
| 「我不知道对方什么情绪」 | 难以命名情绪 | 提供情绪词汇表辅助识别 |

### 情绪词汇参考

| 类别 | 词汇 |
|------|------|
| 基本情绪 | 开心、难过、生气、害怕、惊讶、厌恶 |
| 复合情绪 | 焦虑、失望、委屈、挫败、尴尬、嫉妒 |
| 负面情绪 | 愤怒、悲伤、恐惧、厌恶、羞愧、内疚 |
| 正向情绪 | 满足、自豪、感动、期待、感激、惊喜 |
| 人际情绪 | 被背叛、被忽视、被尊重、被信任、被接纳 |

## 评估与毕业标准

当用户能够在未经提示的情况下，自然运用四步法回应真实沟通场景，即达到毕业标准。

**自我评估表**：每次练习后让用户自评（1-5分）：

```
□ 我做到了先复述，而不是直接回应
□ 我尝试用自己话理解了对方的意思
□ 我说出了对方可能的情绪
□ 我的表达让对方感到被理解
□ 我在对话中没有急于给建议
```

如果以上平均分 ≥ 4 分，说明用户已基本掌握该技能。
