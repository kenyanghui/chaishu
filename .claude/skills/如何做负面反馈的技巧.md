# 如何做负面反馈的技巧 · 教练技能

基于 樊登《可复制的领导力》的教练技能。
拆书家：皖子鼠



## 核心方法论

### What — 这是什么

**如何做负面反馈的技巧** 是关于「如何做负面反馈的技巧」的实用技能。核心原则是：沟通的效果取决于对方的接收，而非自己的表达。只有从对方的角度出发，选择合适的表达方式和内容，才能真正达成沟通目标。

### Why — 为什么重要

在工作和生活中，绝大多数误解和冲突都源于沟通不畅。掌握结构化沟通方法，可以将模糊的表达转化为清晰的信息传递，减少误会、提升效率、改善关系。拆书帮RIA便签法强调"拆为己用"，而沟通正是最需要"拆为己用"的领域。
### How — 操作步骤

  1. **观察场景**：识别当前沟通情境的类型（赞美/批评/谈判/反馈等），明确沟通目标
2. **选择策略**：根据场景选择合适的沟通方法和话术结构
3. **执行沟通**：按照方法步骤进行表达，注意语气和肢体语言
4. **确认效果**：观察对方反应，确认信息被准确接收，必要时调整策略
### Where — 适用场景

「如何做负面反馈的技巧」属于 **沟通与表达** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `可复制的布置任务和正面反馈法` — 可复制的布置任务和正面反馈法
- `做负面反馈的技巧` — 做负面反馈的技巧

建议将同书技能组合学习，形成系统化的 沟通与表达 能力框架。

**跨领域连接：**沟通与表达能力需要与以下领域协同发展：
情绪管理(处理沟通中的情绪)、认知思维(分析沟通对象的需求)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「如何做负面反馈的技巧」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「如何做负面反馈的技巧」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（沟通与表达方向）：**

A. **职场汇报** — 回想一个你最近遇到的职场汇报场景，用今天学到的「如何做负面反馈的技巧」方法重新思考如何应对

B. **同事协作** — 回想一个你最近遇到的同事协作场景，用今天学到的「如何做负面反馈的技巧」方法重新思考如何应对

C. **家庭沟通** — 回想一个你最近遇到的家庭沟通场景，用今天学到的「如何做负面反馈的技巧」方法重新思考如何应对

D. **社交场合** — 回想一个你最近遇到的社交场合场景，用今天学到的「如何做负面反馈的技巧」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「如何做负面反馈的技巧」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「如何做负面反馈的技巧」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「如何做负面反馈的技巧」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「如何做负面反馈的技巧」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
