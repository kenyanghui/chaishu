# 做决策之前首先做什么 · 教练技能

基于 约翰·哈蒙德《决策的艺术》的教练技能。
拆书家：赵德祝



## 核心方法论

### What — 这是什么

**做决策之前首先做什么** 是关于「做决策之前首先做什么」的实用技能。决策质量决定人生质量，而高质量决策依赖于系统的分析框架而非直觉。
### Why — 为什么重要

多数人在面对复杂问题时倾向于用直觉快速判断，但直觉在非熟悉领域往往不可靠。掌握结构化分析工具（如MECE、5Why、决策树）可以显著提升决策质量。拆书帮RIA中的I（Interpretation）环节本质就是一种结构化思考。
### How — 操作步骤

  1. **定义问题**：明确问题的边界和本质，区分"症状"和"根因"
2. **拆解分析**：用MECE等框架将复杂问题拆解为可处理的子问题
3. **生成方案**：针对每个子问题生成多个可选方案，避免二元思维
4. **评估决策**：用决策矩阵等工具评估方案，做出最优选择并执行
### Where — 适用场景

「做决策之前首先做什么」属于 **决策与问题解决** 领域的核心技能。

**延伸阅读：**
参见决策与问题解决领域的其他技能，与本技能配合使用效果更佳。同时推荐了解决策与问题解决领域的基础方法论和进阶技巧，构建完整的知识体系。

**对比分析：**
理解「做决策之前首先做什么」的关键在于与其他方法的对比：

| 对比维度 | 直觉决策 | 结构化决策 |
|---------|---------|-----------|
| **适用场景** | 简单/熟悉/时间紧迫 | 复杂/陌生/高影响 |
| **决策依据** | 经验、感觉、模式识别 | 数据、框架、逻辑推演 |
| **潜在风险** | 认知偏误、盲点 | 分析瘫痪（过度分析） |
| **决策速度** | 快 | 相对较慢但更可靠 |

直觉和结构化不是对立关系，而是互补关系。高手知道什么场景该用直觉（日常低风险决策）、什么场景需要结构化（重大战略决策），并在两者之间找到平衡。

**跨领域连接：**决策与问题解决能力需要与以下领域协同发展：
认知思维（底层思维框架）、学习与成长（从决策中学习）

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「做决策之前首先做什么」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「做决策之前首先做什么」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（决策与问题解决方向）：**

A. **复杂问题分析** — 回想一个你最近遇到的复杂问题分析场景，用今天学到的「做决策之前首先做什么」方法重新思考如何应对

B. **重要决策** — 回想一个你最近遇到的重要决策场景，用今天学到的「做决策之前首先做什么」方法重新思考如何应对

C. **根因分析** — 回想一个你最近遇到的根因分析场景，用今天学到的「做决策之前首先做什么」方法重新思考如何应对

D. **战略规划** — 回想一个你最近遇到的战略规划场景，用今天学到的「做决策之前首先做什么」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「做决策之前首先做什么」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「做决策之前首先做什么」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「做决策之前首先做什么」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「做决策之前首先做什么」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
