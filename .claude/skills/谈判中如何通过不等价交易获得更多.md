# 谈判中如何通过不等价交易获得更多？ · 教练技能

基于 [美] 斯图尔特·戴蒙德《沃顿商学院最受欢迎的谈判课》的教练技能。
拆书家：莫念



## 核心方法论

### What — 这是什么

**谈判中如何通过不等价交易获得更多？** 是关于「谈判中如何通过不等价交易获得更多？」的实用技能。谈判不是零和博弈，而是通过沟通找到双方都能接受的解决方案。优秀的谈判者关注利益而非立场。

### Why — 为什么重要

每天我们都在谈判：谈薪资、定方案、协调资源。不懂谈判的人容易陷入两个极端——要么一味妥协，要么强硬对抗。掌握谈判技巧可以在不破坏关系的前提下争取更多权益。
### How — 操作步骤

  1. **准备分析**：明确自己的底线、目标和BATNA（最佳替代方案），同时分析对方需求
2. **建立关系**：在谈判开始前建立基本信任和良好氛围
3. **探索需求**：通过提问了解对方的真实需求和优先级，而非固守立场
4. **创造价值**：寻找双方利益交集，提出创造性的"双赢"方案
### Where — 适用场景

「谈判中如何通过不等价交易获得更多？」属于 **谈判与说服** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `tf2-1过级` — TF2-1过级
- `如何提高谈判能力争取更多权益` — 如何提高谈判能力，争取更多权益

建议将同书技能组合学习，形成系统化的 谈判与说服 能力框架。

**跨领域连接：**谈判与说服能力需要与以下领域协同发展：
沟通与表达(谈判对话的基础)、情绪管理(谈判中的情绪控制)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「谈判中如何通过不等价交易获得更多？」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「谈判中如何通过不等价交易获得更多？」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（谈判与说服方向）：**

A. **薪资谈判** — 回想一个你最近遇到的薪资谈判场景，用今天学到的「谈判中如何通过不等价交易获得更多？」方法重新思考如何应对

B. **商务合作** — 回想一个你最近遇到的商务合作场景，用今天学到的「谈判中如何通过不等价交易获得更多？」方法重新思考如何应对

C. **跨部门协调** — 回想一个你最近遇到的跨部门协调场景，用今天学到的「谈判中如何通过不等价交易获得更多？」方法重新思考如何应对

D. **冲突调解** — 回想一个你最近遇到的冲突调解场景，用今天学到的「谈判中如何通过不等价交易获得更多？」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「谈判中如何通过不等价交易获得更多？」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「谈判中如何通过不等价交易获得更多？」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「谈判中如何通过不等价交易获得更多？」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「谈判中如何通过不等价交易获得更多？」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
