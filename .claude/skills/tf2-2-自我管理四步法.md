# 自我管理四步法 · 教练技能

基于 史蒂芬·柯维《高效能人士的七个习惯》的教练技能。
拆书家：玥清
拆书日期：2023-07-06

**学习目标**：**
**这个拆页的学习目标是：大家能够运用“自我管理四步法”做好日程安排。**


## 核心方法论

### What — 这是什么

**自我管理四步法** 是关于「自我管理四步法」的实用技能。管理的本质是通过他人完成工作，而非自己亲力亲为。核心在于"目标设定→授权执行→跟踪反馈"的闭环。
### Why — 为什么重要

管理者最大的误区是陷入具体事务而忽略了"通过他人完成工作"的本质。系统化的管理方法可以帮助管理者从"救火队长"转变为"赋能者"，实现团队效能倍增。拆书帮强调"把知识拆为己用"，管理者最需要将管理知识转化为日常管理行为。
### How — 操作步骤

  1. **定义目标**：明确要达成的结果和衡量标准（符合SMART原则）
2. **分解路径**：将目标拆解为可执行的关键步骤和里程碑
3. **授权执行**：明确责任人、资源和支持机制，放手执行
4. **跟踪反馈**：定期检查进展，及时调整偏差，给予建设性反馈
### Where — 适用场景

「自我管理四步法」属于 **管理与领导力** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `tf2-3-觉察协商模式成为关系的创造者` — 觉察协商模式：成为关系的创造者
- `tf2-3-责任型授权` — 责任型授权
- `tf2-1-要事第一` — 要事第一
- `tf1-1-移情聆听四步法` — 移情聆听四步法
- `tf1-2-双赢过程四步法` — 双赢过程四步法

建议将同书技能组合学习，形成系统化的 管理与领导力 能力框架。

**跨领域连接：**管理与领导力能力需要与以下领域协同发展：
沟通与表达(日常管理沟通)、决策与问题解决(管理决策)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「自我管理四步法」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 角色任务：明确和写出自己当前最重要的角色，然后相应的列下来你想要花时间和精力做的一些事情和任务。
  2. 选择目标：在前面列下的事情中，确定一两件重要但不紧急的事务作为下一周的目标，本周给予重点安排。
  3. 制定计划：为列出来的每一项目标安排具体的实施时间，如果你想阅读就可以安排每周三到四天的阅读时间，每天阅读半小时。
  4. 复盘调整：进行每日的优先排序，根据突发事件和一些意外，进行每日的调整。

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（管理与领导力方向）：**

A. **团队目标设定** — 回想一个你最近遇到的团队目标设定场景，用今天学到的「自我管理四步法」方法重新思考如何应对

B. **绩效面谈** — 回想一个你最近遇到的绩效面谈场景，用今天学到的「自我管理四步法」方法重新思考如何应对

C. **任务分配** — 回想一个你最近遇到的任务分配场景，用今天学到的「自我管理四步法」方法重新思考如何应对

D. **跨部门协作** — 回想一个你最近遇到的跨部门协作场景，用今天学到的「自我管理四步法」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「自我管理四步法」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「自我管理四步法」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「自我管理四步法」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

```
伙伴们，还记得你一周之前是如何规划一周的计划，最近什么时候，因为什么突发事情忙得手忙脚乱，导致正常的工作和生活被打断吗？这件事情的被动，是因为你忽略了哪个角色所造成的呢？
请想一想，在小组内分享3分钟，结束后我将请一位伙伴1分钟来分享一下。
 
【学习者案例记录】
婉君：我是公司职员，在公司是一个板块负责人，公司前段时间想要一个部门做一个新的直播项目，我因为以前有过相关的经验，就自作主张把整个直播项目规划和全流程执行方案做出来给了报告，居然搞得其他部门不满意，造成了很多混乱，本来可以呈现给老板加快项目，但不得不暂时停止项目，实际上我忽略了我的角色所造成的，这应该是直播项目的部门长的职责。

感谢小伙伴的分享，让我们了解了忽略角色的影响。

【A2分步催化2】
结合过去的经验，反思类似情况更好的做法应该是如何做呢？请在小组内分享3分钟
 
谢谢大家，如果按照今天我们学习的自我管理四步法，你又…
```
