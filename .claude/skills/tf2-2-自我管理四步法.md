基于 史蒂芬·柯维《高效能人士的七个习惯》的教练技能。

**学习目标**：**
**这个拆页的学习目标是：大家能够运用“自我管理四步法”做好日程安排。**


## 核心方法论

### What — 这是什么

**片段讲解了以第二类事务即非紧急但重要的事务中，如何按照自我管理四个步骤安排日程。
 
**【why-不这样的坏处】**如果你没有按自我管理四步法，按照角色安排自己的时间，就有可能忽略到一些重要角色，可能会让一些不紧急但是很重要的事情没有做到位，导致自己的生活手忙脚乱，乱中出错。
 
**【how】**自我管理四步法就是可以解决这个问题，让我们能够明确好自己的角色和目标，更好的完成自己的计划，促进我们完成更多重要的事情。
1、角色任务：明确和写出自己当前最重要的角色，然后相应的列下来你想要花时间和精力做的一些事情和任务。
2、选择目标：在前面列下的事情中，确定一两件重要但不紧急的事务作为下一周的目标，本周给予重点安排。
3、制定计划：为列出来的每一项目标安排具体的实施时间，如果你想阅读就可以安排每周三到四天的阅读时间，每天阅读半小时。
4、复盘调整：进行每日的优先排序，根据突发事件和一些意外，进行每日的调整。

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「自我管理四步法」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 角色任务：明确和写出自己当前最重要的角色，然后相应的列下来你想要花时间和精力做的一些事情和任务。
  2. 选择目标：在前面列下的事情中，确定一两件重要但不紧急的事务作为下一周的目标，本周给予重点安排。
  3. 制定计划：为列出来的每一项目标安排具体的实施时间，如果你想阅读就可以安排每周三到四天的阅读时间，每天阅读半小时。
  4. 复盘调整：进行每日的优先排序，根据突发事件和一些意外，进行每日的调整。

每一步让用户用自己的话复述，确认理解后再进入下一步。

### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「自我管理四步法」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「自我管理四步法」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

