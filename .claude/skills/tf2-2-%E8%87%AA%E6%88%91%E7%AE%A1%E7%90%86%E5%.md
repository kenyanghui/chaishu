# 自我管理四步法 · 教练技能

基于 史蒂芬·柯维《高效能人士的七个习惯》的教练技能。
拆书家：玥清


## 核心方法论

### What — 这是什么

**片段讲解了以第二类事务即非紧急但重要的事务中，如何按照自我管理四个步骤安排日程。


### How — 操作步骤

  1. 角色任务：明确和写出自己当前最重要的角色，然后相应的列下来你想要花时间和精力做的一些事情和任务。
  2. 选择目标：在前面列下的事情中，确定一两件重要但不紧急的事务作为下一周的目标，本周给予重点安排。
  3. 制定计划：为列出来的每一项目标安排具体的实施时间，如果你想阅读就可以安排每周三到四天的阅读时间，每天阅读半小时。
  4. 复盘调整：进行每日的优先排序，根据突发事件和一些意外，进行每日的调整。

### Where — 适用场景

**根据原文片段，对于我们重要非紧急事件的日程安排，都可以按照自我管理四步法进行制定。

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「自我管理四步法」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

根据回答判断用户所处阶段并针对性辅导。

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 角色任务：明确和写出自己当前最重要的角色，然后相应的列下来你想要花时间和精力做的一些事情和任务。
  2. 选择目标：在前面列下的事情中，确定一两件重要但不紧急的事务作为下一周的目标，本周给予重点安排。
  3. 制定计划：为列出来的每一项目标安排具体的实施时间，如果你想阅读就可以安排每周三到四天的阅读时间，每天阅读半小时。
  4. 复盘调整：进行每日的优先排序，根据突发事件和一些意外，进行每日的调整。

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近用户实际的场景进行练习：

```
场景：<让用户描述一个真实沟通/应用场景>
用户：（尝试应用方法回应）
教练：（给予反馈和指导）
```


### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
伙伴们，还记得你一周之前是如何规划一周的计划，最近什么时候，因为什么突发事情忙得手忙脚乱，导致正常的工作和生活被打断吗？这件事情的被动，是因为你忽略了哪个角色所造成的呢？
请想一想，在小组内分享3分钟，结束后我将请一位伙伴1分钟来分享一下。
```

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
