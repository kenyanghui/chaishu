# 忽视成果对团队的影响 · 教练技能

基于 帕特里克·兰西奥尼《团队协作的五大障碍》的教练技能。
拆书家：小能



## 核心方法论

### What — 这是什么

**忽视成果对团队的影响** 是关于「忽视成果对团队的影响」的实用技能。领导力不是职位赋予的权力，而是通过影响他人共同达成目标的能力。真正的领导者让他人变得更好。

### Why — 为什么重要

很多管理者被提拔是因为个人业务能力强，但"业务高手"和"优秀 leader"需要完全不同的能力模型。领导力的核心是"通过他人完成工作"而不是"自己做得更好"。
### How — 操作步骤

  1. **建立信任**：通过言行一致、坦诚沟通建立个人信誉和团队信任
2. **明确方向**：为团队设定清晰的愿景、目标和优先级
3. **赋能团队**：提供资源、清除障碍、授权决策，而非微观管理
4. **持续反馈**：建立双向反馈机制，及时肯定进步、调整偏差
### Where — 适用场景

「忽视成果对团队的影响」属于 **团队与领导力** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `团队协作的五大障碍中的逃避责任` — 团队协作的五大障碍中的逃避责任
- `团队协作的五大障碍之逃避责任` — 团队协作的五大障碍之逃避责任

建议将同书技能组合学习，形成系统化的 团队与领导力 能力框架。

**跨领域连接：**团队与领导力能力需要与以下领域协同发展：
沟通与表达(领导力沟通)、管理与领导力(团队管理)

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「忽视成果对团队的影响」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「忽视成果对团队的影响」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（团队与领导力方向）：**

A. **新团队组建** — 回想一个你最近遇到的新团队组建场景，用今天学到的「忽视成果对团队的影响」方法重新思考如何应对

B. **团队士气低落** — 回想一个你最近遇到的团队士气低落场景，用今天学到的「忽视成果对团队的影响」方法重新思考如何应对

C. **变革推动** — 回想一个你最近遇到的变革推动场景，用今天学到的「忽视成果对团队的影响」方法重新思考如何应对

D. **培养接班人** — 回想一个你最近遇到的培养接班人场景，用今天学到的「忽视成果对团队的影响」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「忽视成果对团队的影响」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「忽视成果对团队的影响」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「忽视成果对团队的影响」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「忽视成果对团队的影响」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
