# 效能情景演练 · 教练技能

基于 史蒂芬·柯维《高效能人士的七个习惯》的教练技能。
拆书家：玥清
拆书日期：2023-07-15

**学习目标**：**
这个拆页的学习目标是：大家能够体验用软件工具加深对“个人效能情境”的学习感受


## 核心方法论

### What — 这是什么

**效能情景演练** 是关于「效能情景演练」的实用技能。管理的本质是通过他人完成工作，而非自己亲力亲为。核心在于"目标设定→授权执行→跟踪反馈"的闭环。
### Why — 为什么重要

管理者最大的误区是陷入具体事务而忽略了"通过他人完成工作"的本质。系统化的管理方法可以帮助管理者从"救火队长"转变为"赋能者"，实现团队效能倍增。拆书帮强调"把知识拆为己用"，管理者最需要将管理知识转化为日常管理行为。
### How — 操作步骤

  1. **定义目标**：明确要达成的结果和衡量标准（符合SMART原则）
2. **分解路径**：将目标拆解为可执行的关键步骤和里程碑
3. **授权执行**：明确责任人、资源和支持机制，放手执行
4. **跟踪反馈**：定期检查进展，及时调整偏差，给予建设性反馈
### Where — 适用场景

「效能情景演练」属于 **管理与领导力** 领域的核心技能。

**关联技能（同一书籍来源）：**
- `tf2-3-觉察协商模式成为关系的创造者` — 觉察协商模式：成为关系的创造者
- `tf2-3-责任型授权` — 责任型授权
- `tf2-1-要事第一` — 要事第一
- `tf1-1-移情聆听四步法` — 移情聆听四步法
- `tf1-2-双赢过程四步法` — 双赢过程四步法

建议将同书技能组合学习，形成系统化的 管理与领导力 能力框架。

**延伸阅读：**
参见管理与领导力领域的其他技能，与本技能配合使用效果更佳。同时推荐了解管理与领导力领域的基础方法论和进阶技巧，构建完整的知识体系。

**对比分析：**
理解「效能情景演练」的关键在于与其他方法的对比：

| 对比维度 | 指令式管理 | 赋能式管理 |
|---------|-----------|-----------|
| **核心目标** | 确保执行标准化、高效率 | 激发主动性、创造力 |
| **适用场景** | 紧急任务、新人带教 | 复杂问题、资深员工 |
| **管理者角色** | 指挥者、监督者 | 教练、资源提供者 |
| **决策方式** | 自上而下决策 | 授权团队自主决策 |

区分两种管理模式的本质是"对事"与"对人"——对执行层面需要清晰指令，对能力发展需要赋能授权。优秀管理者不是二选一，而是根据任务性质和人员成熟度动态切换。

**跨领域连接：**管理与领导力能力需要与以下领域协同发展：
沟通与表达（日常管理沟通）、决策与问题解决（管理决策）

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「效能情景演练」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 确定角色：明确和写出自己当前最重要的角色，注意要尽量详尽不要遗漏，一般会包含在职场、家庭和个人关系上的角色，对于我来说，下一周我的角色有企业顾问、先生、儿子、父亲、拆书家。
  2. 列出任务：列下来你想要花时间和精力做的一些事情和任务，这一步的内容可以用幕布工具整理出来，就好像我的这个幕布软件界面，例如我是企业顾问（按照协议交付结果）、先生（支持太太的家庭教育和情志疗法学习）儿子（带母亲缓解糖尿病困扰）父亲（陪伴和照顾3个孩子）拆书家（完成并通过二级的过级）。
  3. 选择目标：在前面列下的事情中，确定一两件重要但不紧急的事务作为下一周的目标，这一步可以用Todo工具软件进行管理，例如屏幕上这个就是我用来管理的微软Todo软件，本周给予重点安排，在开始时再在软件上进行确认。选择目标要注意与相关的关系人进行沟通，得到关系人的确认才能更好的执行，例如我如果选择父亲（陪伴和照顾3个孩子，为这个假期开始做好规则）和拆书家（二级过级），那么我要跟3个孩子和太太沟通这个目标得到支持，也要跟拆书过级的师父和组织长老等进行沟通。
  4. 制定计划：为列出来的每一项目标安排具体的实施时间，并写入每日日程安排，以Todo软件工具来提醒自己。例如你想阅读就可以安排每周三到四天的阅读时间，每天阅读半小时，这样每次阅读结束，我都可以在微软Todo上打个勾，让自己获得任务完成得激励。而作为父亲，在接下来一周时间内，我都找时间跟孩子谈好假期规则，做好孩子榜样，让孩子自己制定计划，陪伴和看见孩子的成长和进步。作为拆书家，接下来需要花费至少4小时准备过级预备表和PPT，于周六下午进行拆书过级。
  5. 复盘调整：进行每日的优先排序，根据突发事件和一些意外，进行每日的调整，做到心中有数。例如我在每天Todo的回顾和OneNote日记记录，都会相应的更新内容，也便于每周和每月的回顾。而作为父亲陪伴和谈话，如果某个孩子时间冲突问题白天没能有机会，我就调整为晚上睡觉前跟孩子们简单聊。作为拆书家，因为临时工作或一些不可抗拒的因素导致没能按计划准备，我就调整为晚上孩子们睡觉后安静下来完成。

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（管理与领导力方向）：**

A. **团队目标设定** — 回想一个你最近遇到的团队目标设定场景，用今天学到的「效能情景演练」方法重新思考如何应对

B. **绩效面谈** — 回想一个你最近遇到的绩效面谈场景，用今天学到的「效能情景演练」方法重新思考如何应对

C. **任务分配** — 回想一个你最近遇到的任务分配场景，用今天学到的「效能情景演练」方法重新思考如何应对

D. **跨部门协作** — 回想一个你最近遇到的跨部门协作场景，用今天学到的「效能情景演练」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「效能情景演练」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A3 场景应用 — 现场演练

```
【场景设计】
拆书家玥清这段时间特忙，还经常出差，最近两个月需要尽快过三级拆书家，最近突发的工作和学习计划也让晚上挤得满满当当，这样家里太太有意见了，太太对玥清这种整天学习的做法不理解，因为将全家人说好的早睡计划和节奏打乱了。现在你是玥清在拆书帮的朋友聪聪，你如何通过四步法来帮助玥清调整自己对事情的安排，让玥清的效能提高也可以让全家人早睡早起？（角色扮演）
 
【现场演练】现在两人一组，离我近的扮演玥清，离我远的扮演玥清在拆书帮的朋友聪聪，进行小组内演练5分钟，结束后我们请一组伙伴出来演练给大家看，时间5分钟内。
 
【现场演练记录】以下由两位学习者扮演玥清和聪聪：
 
玥清：这两个月突然好忙呀，还经常出差，但是又想抓紧把三级拆书家过了，这两天突发事件就更加忙了，本来暑假说好了全家都要早睡早起，现在节奏全被打乱了，现在不知怎么办了？
聪聪：最近看了一本书《高效能人士的七个习惯》，其中有一个…
```

### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「效能情景演练」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「效能情景演练」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「效能情景演练」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

从以下维度评估：

| 维度 | 描述 |
