# 移情聆听四步法 · 教练技能

基于 史蒂芬·柯维《高效能人士的七个习惯》的教练技能。
拆书家：玥清


## 核心方法论

### What — 这是什么

听还要学吗？我们从小到大，只要是个正常人，不是都天天在听别人说吗？但是，你真的懂得听吗？
回想一下，你有没有过心不在焉的听别人说话，听一半没另一半的情况，或者完全就抓不到别人说的意思？
现在分享的就是基于同理心的高级聆听方法，可以帮助听者充分理解讲者并获得更好的沟通效果。

### Why — 为什么重要

在家庭中，我们往往不重视家人的感受，没有好好聆听最亲近的家人导致争吵不断；在职场中，我们往往受限于思维和立场，没有好好聆听就无法构建良好的协作环境。这次学会“耳到、眼到、心到”的移情聆听，就是为了能够让我们建立人与人心的链接，达成良好的沟通。

### How — 操作步骤

  1. 复述语句，表现专心聆听的态度。
  2. 加入解释，表达左脑理解后的话。
  3. 个人感觉，加上右脑体会情绪。
  4. 带情解释，左右脑并带情感解释。

### Where — 适用场景

移情聆听适用于家庭、朋友、同事之间的沟通，适合于商业谈判的场景。尤其在负面情绪发生时，移情聆听往往会有意想不到的效果，本质上是构建了一个同理心的沟通关系，关键是作为听者能够耐心感受到讲者的痛苦，并努力提供帮助。

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「移情聆听四步法」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

根据回答判断用户所处阶段并针对性辅导。

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 复述语句，表现专心聆听的态度。
  2. 加入解释，表达左脑理解后的话。
  3. 个人感觉，加上右脑体会情绪。
  4. 带情解释，左右脑并带情感解释。

每一步让用户用自己的话复述，确认理解后再进入下一步。

选择一个贴近用户实际的场景进行练习：

