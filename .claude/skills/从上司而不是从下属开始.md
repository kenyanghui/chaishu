# 从上司而不是从下属开始 · 教练技能

基于 拉姆·查兰《领导梯队》的教练技能。
拆书家：钱艳



## 核心方法论

### What — 这是什么

**从上司而不是从下属开始** 是关于「从上司而不是从下属开始」的实用技能。管理的本质是通过他人完成工作，而非自己亲力亲为。核心在于"目标设定→授权执行→跟踪反馈"的闭环。
### Why — 为什么重要

管理者最大的误区是陷入具体事务而忽略了"通过他人完成工作"的本质。系统化的管理方法可以帮助管理者从"救火队长"转变为"赋能者"，实现团队效能倍增。拆书帮强调"把知识拆为己用"，管理者最需要将管理知识转化为日常管理行为。
### How — 操作步骤

  1. **定义目标**：明确要达成的结果和衡量标准（符合SMART原则）
2. **分解路径**：将目标拆解为可执行的关键步骤和里程碑
3. **授权执行**：明确责任人、资源和支持机制，放手执行
4. **跟踪反馈**：定期检查进展，及时调整偏差，给予建设性反馈
### Where — 适用场景

「从上司而不是从下属开始」属于 **管理与领导力** 领域的核心技能。

**延伸阅读：**
参见管理与领导力领域的其他技能，与本技能配合使用效果更佳。同时推荐了解管理与领导力领域的基础方法论和进阶技巧，构建完整的知识体系。

**对比分析：**
理解「从上司而不是从下属开始」的关键在于与其他方法的对比：

| 对比维度 | 指令式管理 | 赋能式管理 |
|---------|-----------|-----------|
| **核心目标** | 确保执行标准化、高效率 | 激发主动性、创造力 |
| **适用场景** | 紧急任务、新人带教 | 复杂问题、资深员工 |
| **管理者角色** | 指挥者、监督者 | 教练、资源提供者 |
| **决策方式** | 自上而下决策 | 授权团队自主决策 |

区分两种管理模式的本质是"对事"与"对人"——对执行层面需要清晰指令，对能力发展需要赋能授权。优秀管理者不是二选一，而是根据任务性质和人员成熟度动态切换。

**跨领域连接：**管理与领导力能力需要与以下领域协同发展：
沟通与表达（日常管理沟通）、决策与问题解决（管理决策）

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「从上司而不是从下属开始」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「从上司而不是从下属开始」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（管理与领导力方向）：**

A. **团队目标设定** — 回想一个你最近遇到的团队目标设定场景，用今天学到的「从上司而不是从下属开始」方法重新思考如何应对

B. **绩效面谈** — 回想一个你最近遇到的绩效面谈场景，用今天学到的「从上司而不是从下属开始」方法重新思考如何应对

C. **任务分配** — 回想一个你最近遇到的任务分配场景，用今天学到的「从上司而不是从下属开始」方法重新思考如何应对

D. **跨部门协作** — 回想一个你最近遇到的跨部门协作场景，用今天学到的「从上司而不是从下属开始」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「从上司而不是从下属开始」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「从上司而不是从下属开始」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「从上司而不是从下属开始」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「从上司而不是从下属开始」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
