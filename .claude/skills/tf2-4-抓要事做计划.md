## 核心方法论

### What — 这是什么

**抓要事，做计划** 是关于「抓要事，做计划」的实用技能。效能≠忙碌，效能 = 产出 / 投入。核心是做"正确的事"而非"正确地做事"，并把精力投入在真正重要的事情上。
### Why — 为什么重要

每天24小时对所有人都公平，区别在于如何使用。高效能人士并非更勤奋，而是更善于区分"重要"与"紧急"，并敢于对不重要的事情说"不"。
### How — 操作步骤

  1. **厘清要事**：从众多任务中识别出真正重要的高杠杆活动（二八原则）
2. **规划时间**：为要事预留不受干扰的整块时间，而非填满日程
3. **执行聚焦**：一次只做一件事，使用番茄工作法等工具保持专注
4. **复盘优化**：定期回顾时间使用情况，识别并消除时间黑洞
### Where — 适用场景

「抓要事，做计划」属于 **效能与时间管理** 领域的核心技能。

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「抓要事，做计划」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 列事务清单，就是调查汇总把要做的所有事务一项项具体列出来。
  2. 按四类排序，把要做的事务按重要程度和紧迫程度维度分成重要并紧迫的事情、重要不紧迫的事情、不重要紧迫的事情、不重要不紧迫的事情，归类和排序到时间管理矩阵里。
  3. 明确并执行，明确所列的第二类事务是重要不紧迫的事情，调整策略花80%时间和精力放在第二类事务上。

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（效能与时间管理方向）：**

A. **每日任务规划** — 回想一个你最近遇到的每日任务规划场景，用今天学到的「抓要事，做计划」方法重新思考如何应对

B. **长期项目推进** — 回想一个你最近遇到的长期项目推进场景，用今天学到的「抓要事，做计划」方法重新思考如何应对

C. **多任务处理** — 回想一个你最近遇到的多任务处理场景，用今天学到的「抓要事，做计划」方法重新思考如何应对

D. **克服拖延** — 回想一个你最近遇到的克服拖延场景，用今天学到的「抓要事，做计划」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「抓要事，做计划」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考：

```
教练引导：「**
现在请你回忆下最近一周的工作一天或者休息日的一天你是如何度过的？在这一天中你处理了哪些事务，例如看邮件、看网页、聊天、准备计划等等，哪些让你感到忙忙碌碌却没有什么成就感？
 
或者你能够思考及早的注意健康管理，学习家庭教育，做好长期财务规划之类的问题。请大家思考并列举出来，时间是1 分钟。思考完后，请一位小伙伴分享一下。」
```

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「抓要事，做计划」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
