# 凭感觉做顶级成长 · 教练技能

基于 周岭《认知觉醒》的教练技能。
拆书家：玥清
拆书日期：2026-05-10

**学习目标**：**
跟随我完成本次的拆书，学习者能够使用“**感知-触动-确认-行动”的激活感觉FTCA四步法**（“Feel-Touch-Confirm-Action”）来写出完整的小剧本，小剧本的内容能够体现出“凭感觉”的成长方法。


## 核心方法论

### What — 这是什么

**凭感觉做顶级成长** 是关于「凭感觉做顶级成长」的实用技能。人的行为受认知框架的约束，改变认知才能从根本上改变行为。核心是通过反思和刻意练习，实现认知层级的跃迁。

### Why — 为什么重要

查理·芒格说："手里拿着锤子，看什么都是钉子。"单一思维模型会导致认知偏差。拓展认知工具箱，用多维度视角分析问题，是应对复杂世界的核心能力。
### How — 操作步骤

  1. **突破惯性**：识别当前思维模式的局限和惯性，打破默认假设
2. **引入框架**：运用新的思维模型或认知框架重新审视问题
3. **深度加工**：将新知识与已有知识体系连接，深度加工内化
4. **反思迭代**：在实践中反思认知升级的效果，持续优化思维模式
### Where — 适用场景

「凭感觉做顶级成长」属于 **认知思维** 领域的核心技能。

**跨领域连接：**认知思维能力需要与以下领域协同发展：
决策与问题解决(思维模型的应用)、学习与成长(持续升级认知)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「凭感觉做顶级成长」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 感知：不钻牛角尖、不偷懒，找不太难、不简单，踮踮脚能学会的内容，不熬困难区、不躺舒适区。
  2. 触动：不贪多，只找最戳自己、印象最深的那一个点。
  3. 确认：问问自己，这个触动点真的让自己开心、愿意花时间琢磨吗？适合自己就选它。
  4. 行动：不搞大计划，从最小行动开始，抓住一个点深入做、落地实践。

每一步让用户用自己的话复述，确认理解后再进入下一步。

选择一个贴近你实际生活或工作的场景进行练习：
