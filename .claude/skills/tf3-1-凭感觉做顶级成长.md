# 凭感觉做顶级成长 · 教练技能

基于 周岭《认知觉醒》的教练技能。
拆书家：玥清
拆书日期：2026-05-10

**学习目标**：**
跟随我完成本次的拆书，学习者能够使用“**感知-触动-确认-行动”的激活感觉FTCA四步法**（“Feel-Touch-Confirm-Action”）来写出完整的小剧本，小剧本的内容能够体现出“凭感觉”的成长方法。


## 核心方法论

### What — 这是什么

**
从拆页中可以了解：凭感觉不是任性妄为，而是找对成长方向、不焦虑的好方法，核心就是找适合自己、跳一跳能学会的内容，只抓一个最有感觉的点扎实做，实现实实在在的成长。

凭感觉有四个关键词：
1. 感知：不钻牛角尖、不偷懒，找不太难、不简单，踮踮脚能学会的内容，不熬困难区、不躺舒适区。
2. 触动：不贪多，只找最戳自己、印象最深的那一个点。
3. 确认：问问自己，这个触动点真的让自己开心、愿意花时间琢磨吗？适合自己就选它。
4. 行动：不搞大计划，从最小行动开始，抓住一个点深入做、落地实践。

我再用读书这个最常见的主题，给大家拆成5个场景，咱们一个一个叠加着来，结合场景再加深一遍印象，希望大家听完就彻底明白。
场景 1：0 个关键词（完全没有凭感觉）
特别简单，平时根本不读书，突然拿到一本书，脑子一热就立flag：一天之内必须读完，恨不得一口吃成胖子。
结果呢？越读越费劲，越读越焦虑，最后干脆把书一扔，直接躺平刷手机，啥也没学到，等于白忙活。


### How — 操作步骤

  1. 感知：不钻牛角尖、不偷懒，找不太难、不简单，踮踮脚能学会的内容，不熬困难区、不躺舒适区。
  2. 触动：不贪多，只找最戳自己、印象最深的那一个点。
  3. 确认：问问自己，这个触动点真的让自己开心、愿意花时间琢磨吗？适合自己就选它。
  4. 行动：不搞大计划，从最小行动开始，抓住一个点深入做、落地实践。

### Where — 适用场景

**
学习只是冰山一角，“凭感觉” 适用于生活的方方面面，尤其在面临重大的人生问题时，如选择伴侣、职业转型、寻找人生目标、沟通合作伙伴等。

**【how】**
从书中提炼出可以直接用的 **激活感觉FTCA四步法**，每一步都讲清楚具体怎么做，而且不局限于读书，生活里方方面面都能用：

**1. 感知Feel：快速判断，找准边界**
停下来，安静30秒，只问自己一句话：这件事/这个人，我是轻松能接住、有点兴趣，还是觉得太累太压抑，或是太无聊没感觉？这样就可以应用在除了读书外的其他地方了。
例子：不管是选学习项目、找合作伙伴，还是选兴趣爱好，都可以用这句话快速感知——比如纠结要不要学演讲，安静30秒问自己，是觉得轻松有兴趣，还是觉得压抑不敢尝试，瞬间就能找准自己的拉伸区。

**2. 触动Touch：盯住本能，找到热爱**
盯住内心第一本能反应：有没有哪一瞬间，让我心里一亮、有点期待、想靠
