## 教练流程

### 第一步：诊断 — 了解用户当前水平

```

遇到过什么困难或困惑吗？」

```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「从单机学习到联机协作，用碎片化输出实现效能跃迁」的核心要点和关键方法

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近用户实际的场景进行练习：

```

```


### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「从单机学习到联机协作，用碎片化输出实现效能跃迁」方面有没有成功的经验或失败的教训？

```

**示例引导**：
- 你遇到过需要「从单机学习到联机协作，用碎片化输出实现效能跃迁」的场景吗？
- 当时你是怎么做的？结果如何？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```

3. 预期效果：______
4. 如何复盘：______」
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。
