## 核心方法论

### What — 这是什么

**精进：如何成为一个很厉害的人** 是关于「精进：如何成为一个很厉害的人」的实用技能。人的行为受认知框架的约束，改变认知才能从根本上改变行为。核心是通过反思和刻意练习，实现认知层级的跃迁。

### Why — 为什么重要

查理·芒格说："手里拿着锤子，看什么都是钉子。"单一思维模型会导致认知偏差。拓展认知工具箱，用多维度视角分析问题，是应对复杂世界的核心能力。
### How — 操作步骤

  1. **突破惯性**：识别当前思维模式的局限和惯性，打破默认假设
2. **引入框架**：运用新的思维模型或认知框架重新审视问题
3. **深度加工**：将新知识与已有知识体系连接，深度加工内化
4. **反思迭代**：在实践中反思认知升级的效果，持续优化思维模式
### Where — 适用场景

「精进：如何成为一个很厉害的人」属于 **认知思维** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `tf3-3-精进` — 精进

建议将同书技能组合学习，形成系统化的 认知思维 能力框架。

**跨领域连接：**认知思维能力需要与以下领域协同发展：
决策与问题解决(思维模型的应用)、学习与成长(持续升级认知)

## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「精进：如何成为一个很厉害的人」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「精进：如何成为一个很厉害的人」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（认知思维方向）：**

A. **决策失误复盘** — 回想一个你最近遇到的决策失误复盘场景，用今天学到的「精进：如何成为一个很厉害的人」方法重新思考如何应对

B. **思维僵化** — 回想一个你最近遇到的思维僵化场景，用今天学到的「精进：如何成为一个很厉害的人」方法重新思考如何应对

C. **学习新领域** — 回想一个你最近遇到的学习新领域场景，用今天学到的「精进：如何成为一个很厉害的人」方法重新思考如何应对

D. **跨界创新** — 回想一个你最近遇到的跨界创新场景，用今天学到的「精进：如何成为一个很厉害的人」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「精进：如何成为一个很厉害的人」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「精进：如何成为一个很厉害的人」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

- 当时你是怎么做的？结果如何？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```

请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进
