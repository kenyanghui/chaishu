# 漏斗模式 · 教练技能

## 核心方法论

### What — 这是什么

基于 [美] 托尼·斯托茨福斯《提问的威力：教练问题全清单》中关于「漏斗模式」的核心方法。

### How — 操作步骤

  1. 理解「漏斗模式」的核心概念和原理
  2. 按照方法步骤逐步练习和应用
  3. 结合实际场景复盘，形成自己的经验

### Where — 适用场景

- 需要应用「漏斗模式」的各种场景
- 希望提升相关能力的日常练习
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「漏斗模式」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 理解「漏斗模式」的核心概念和原理
  2. 按照方法步骤逐步练习和应用
  3. 结合实际场景复盘，形成自己的经验

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近用户实际的场景进行练习：

```
场景：<让用户描述一个真实应用场景>
用户：（尝试应用方法回应）
教练：（给予反馈和指导）
```


### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「漏斗模式」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「漏斗模式」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「漏斗模式」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
