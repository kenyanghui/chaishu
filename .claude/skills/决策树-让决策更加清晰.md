# 决策树—让决策更加清晰 · 教练技能

基于 卡尔·斯佩茨勒《斯坦福商业决策课》的教练技能。
拆书家：王辰



## 核心方法论

### What — 这是什么

**决策树—让决策更加清晰** 是关于「决策树—让决策更加清晰」的实用技能。决策质量决定人生质量，而高质量决策依赖于系统的分析框架而非直觉。

### Why — 为什么重要

多数人在面对复杂问题时倾向于用直觉快速判断，但直觉在非熟悉领域往往不可靠。掌握结构化分析工具（如MECE、5Why、决策树）可以显著提升决策质量。拆书帮RIA中的I（Interpretation）环节本质就是一种结构化思考。
### How — 操作步骤

  1. **定义问题**：明确问题的边界和本质，区分"症状"和"根因"
2. **拆解分析**：用MECE等框架将复杂问题拆解为可处理的子问题
3. **生成方案**：针对每个子问题生成多个可选方案，避免二元思维
4. **评估决策**：用决策矩阵等工具评估方案，做出最优选择并执行
### Where — 适用场景

「决策树—让决策更加清晰」属于 **决策与问题解决** 领域的核心技能。

**跨领域连接：**决策与问题解决能力需要与以下领域协同发展：
认知思维(底层思维框架)、学习与成长(从决策中学习)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「决策树—让决策更加清晰」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「决策树—让决策更加清晰」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（决策与问题解决方向）：**

A. **复杂问题分析** — 回想一个你最近遇到的复杂问题分析场景，用今天学到的「决策树—让决策更加清晰」方法重新思考如何应对

B. **重要决策** — 回想一个你最近遇到的重要决策场景，用今天学到的「决策树—让决策更加清晰」方法重新思考如何应对

C. **根因分析** — 回想一个你最近遇到的根因分析场景，用今天学到的「决策树—让决策更加清晰」方法重新思考如何应对

D. **战略规划** — 回想一个你最近遇到的战略规划场景，用今天学到的「决策树—让决策更加清晰」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「决策树—让决策更加清晰」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```

```

当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
```

- 当时你是怎么做的？结果如何？

引导用户制定具体行动计划：

```

1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」

```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
