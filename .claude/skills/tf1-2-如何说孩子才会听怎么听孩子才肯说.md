# 如何说孩子才会听怎么听孩子才肯说 · 教练技能

基于 [美]阿黛尔•法伯 伊莱恩•玛兹丽施《如何说孩子才会听，怎么听孩子才肯说》的教练技能。
拆书家：高燕



## 核心方法论

### What — 这是什么

**如何说孩子才会听怎么听孩子才肯说** 是关于「如何说孩子才会听怎么听孩子才肯说」的实用技能。核心理念是：教育的前提是关系，关系的前提是尊重。只有先建立情感连接，才能有效引导行为改变。

### Why — 为什么重要

传统的"命令-服从"式亲子教育正在被"尊重-引导"式方法取代。研究表明，高压教育短期内"有效"，但长期会损害孩子的自主性和亲子关系。正面管教等方法提供了"既尊重孩子、又坚定原则"的第三条路。
### How — 操作步骤

  1. **接纳感受**：识别并接纳孩子的情绪，不评判、不说教
2. **连接理解**：用共情式语言表达理解，建立情感连接
3. **引导解决**：在孩子情绪平复后，引导其思考解决方案
4. **赋能行动**：鼓励孩子自主决策，给予适度的选择权
### Where — 适用场景

「如何说孩子才会听怎么听孩子才肯说」属于 **亲子教育** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `tf2-2-亲子沟通技巧` — 亲子沟通技巧
- `tf2-2-帮助孩子面对他们的感受` — 帮助孩子面对他们的感受

建议将同书技能组合学习，形成系统化的 亲子教育 能力框架。

**跨领域连接：**亲子教育能力需要与以下领域协同发展：
沟通与表达(亲子沟通本质是沟通)、情绪管理(应对孩子情绪)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「如何说孩子才会听怎么听孩子才肯说」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「如何说孩子才会听怎么听孩子才肯说」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（亲子教育方向）：**

A. **孩子发脾气** — 回想一个你最近遇到的孩子发脾气场景，用今天学到的「如何说孩子才会听怎么听孩子才肯说」方法重新思考如何应对

B. **作业拖延** — 回想一个你最近遇到的作业拖延场景，用今天学到的「如何说孩子才会听怎么听孩子才肯说」方法重新思考如何应对

C. **兄弟姐妹冲突** — 回想一个你最近遇到的兄弟姐妹冲突场景，用今天学到的「如何说孩子才会听怎么听孩子才肯说」方法重新思考如何应对

D. **日常习惯培养** — 回想一个你最近遇到的日常习惯培养场景，用今天学到的「如何说孩子才会听怎么听孩子才肯说」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「如何说孩子才会听怎么听孩子才肯说」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「如何说孩子才会听怎么听孩子才肯说」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「如何说孩子才会听怎么听孩子才肯说」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```

请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。
