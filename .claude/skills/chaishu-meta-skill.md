# 拆书元技能 · AI拆书工坊课程总管

基于玥清《AI拆书工坊》的元技能，统领288+教练技能，为拆书家提供个性化学习路径。
拆书家：玥清
拆书日期：2026-05-22

**课程定位**：成人学习的术教练 — 用AI辅助拆书法，帮助成人掌握高效学习的艺术。


## 核心方法论

### What — 这是什么

拆书元技能是一个**技能管理器**和**课程总管**，它：

1. **诊断**你的当前拆书等级（从入门到三级拆书家）
2. **推荐**最匹配你当前阶段的教练技能（从288+个SKILL.md中筛选）
3. **引导**你进入AI拆书管线（女娲蒸馏→仓颉拆书→高清大图→ljg-card→达尔文进化）
4. **追踪**你的成长轨迹，持续优化推荐

它不是替代拆书帮的过级体系，而是建立在TF认证体系之上的**AI辅助学习伴侣**。

### Why — 为什么需要元技能

拆书帮发展至今，已积累了大量优质拆书内容：

- **288+教练技能**覆盖沟通、管理、认知、领导力等多个领域
- **TF1-1到TF3-3**六级过级体系，每级都有明确的技能要求
- **69本书、156个拆页**的丰富内容库

但学习者面临的核心痛点是：

| 痛点 | 表现 | 元技能如何解决 |
|------|------|----------------|
| **信息过载** | 288个技能不知从何开始 | 按等级自动筛选推荐 |
| **路径不清** | 不知道TF1→TF2→TF3每级要练什么 | 清晰展示每级核心技能 |
| **AI脱节** | 不知道AI如何辅助拆书 | 引导进入AI拆书管线 |
| **进阶瓶颈** | 卡在某一级不知道如何突破 | 诊断薄弱环节，精准推荐 |

### How — 操作步骤（4级诊断流程）

元技能通过结构化对话完成诊断和推荐，分为四个阶段：

---

#### Stage 1: 诊断 — 了解用户当前水平

教练引导用户回答三个关键问题：

```
问题1：你目前拆书过级到哪个阶段了？
  □ 还没开始（零基础）
  □ TF1-1 / TF1-2（基础拆书家）
  □ TF2-1 / TF2-2 / TF2-3 / TF2-4（拆书教练）
  □ TF3-1 / TF3-2 / TF3-3（高级拆书家）
  □ 已过三级（想进阶AI拆书家）

问题2：最近想练什么技能方向？
  □ 沟通表达    □ 时间管理    □ 领导力
  □ 亲子教育    □ 认知思维    □ 教练技术
  □ 目标管理    □ 情绪管理    □ 学习方法

问题3：你使用AI辅助拆书的程度？
  □ 完全没用过  □ 偶尔用  □ 熟练用  □ 想进阶AI拆书家
```

#### Stage 2: 映射 — 匹配技能等级

根据诊断结果，映射到四个学习等级之一：

| 等级 | 对应TF级别 | 技能数量 | 核心目标 |
|------|------------|----------|----------|
| **Level 1: 基础拆书家** | TF1-1 ~ TF1-2 | ~18个 | 掌握RIA便签法，能独立过级 |
| **Level 2: 拆书教练** | TF2-1 ~ TF2-4 | ~34个 | 能设计拆书课，引导学习者 |
| **Level 3: 高级拆书家** | TF3-1 ~ TF3-3 | ~13个 | 能带徒弟，设计工作坊 |
| **Level 4: AI拆书家** | 元技能+AI管线 | 全部技能 | 用AI重构拆书流程 |

#### Stage 3: 推荐 — 输出学习路径

为每个等级输出结构化的技能推荐清单：

```
📋 Level N: [等级名称] 推荐学习方案

当前等级核心技能：
1. [技能名1] — TF级别，来源书籍 — 一句话说明
2. [技能名2] — TF级别，来源书籍 — 一句话说明
...

晋级下一级需掌握：
→ [关键技能A]：为什么这个技能是门槛
→ [关键技能B]：为什么这个技能是门槛

[如果是Level 4] AI管线推荐：
→ 女娲蒸馏：用AI分析作者思想体系
→ 仓颉拆书：自动提取RIA内容生成技能
```

#### Stage 4: 接入 — 引导进入AI管线

当用户达到Level 4（AI拆书家）阶段，引导进入完整管线：

```
女娲蒸馏 → 仓颉拆书 → 高清大图 → ljg-card → 达尔文进化
     ↓            ↓           ↓           ↓           ↓
  作者思想      RIA拆解    知识视觉化   Anki卡片    技能持续
  知识图谱      SKILL.md   信息图      间隔复习     优化迭代
```

### Where — 适用场景

- **新拆书家**刚入帮，不知道从哪里开始 — 元技能给出入门路径
- **正在过级的拆书家**卡在某个TF级别需要突破 — 精准推荐突破技能
- **三级拆书家**想转型AI拆书家 — 引导进入AI管线
- **企业学习者**想基于拆书体系自学某类技能 — 按技能方向筛选推荐
- **拆书帮分舵主**想了解会员整体学习进度 — 作为培训框架参考


## 课程框架：成人学习的术教练

### 课程定位

"成人学习的术教练"（The Art of Adult Learning Coach）是一门融合**RIA拆书法**与**AI工具**的实践课程，目标是帮助拆书家：

1. **学** — 掌握成人学习的底层方法论
2. **练** — 通过拆书过级实战练习
3. **教** — 成为能带徒弟的拆书教练
4. **进化** — 用AI工具进化成为AI拆书家

### Module 0: 入学诊断

- 拆书帮是什么？（RIA拆书法概述）
- 你的学习目标是什么？（过级 / 技能提升 / 成为AI拆书家）
- 当前水平自评（TF0 ~ TF3）
- 推荐学习路径

### Module 1: 基础拆书 TF1 — 学

核心方法论：
- RIA便签法基础：R阅读拆页、I讲解引导、A拆为己用
- 如何提取拆页（Reading）：精选原文片段
- 如何鲜活内化（Interpretation）：What-Why-How-Where框架
- 如何催化应用（Appropriation）：A1激活经验→A2催化应用

TF1-1核心技能包：
- 移情聆听四步法 · 史蒂芬·柯维《高效能人士的七个习惯》
- 拒绝后撤三步法 · 罗伯特·西奥迪尼《影响力》
- 高质量赞美三步法 · 沟通类书籍
- 自控力三步法 · 凯利·麦格尼格尔《自控力》
- 检视阅读 · 赵周《这样读书就够了》

TF1-2晋级技能包：
- SCQA搭建序言 · 李忠秋《结构思考力》
- 双赢过程四步法 · 史蒂芬·柯维《高效能人士的七个习惯》
- 赢得合作四步法 · 简·尼尔森《正面管教》

**里程碑**：完成TF1-1和TF1-2过级，掌握RIA便签法

### Module 2: 拆书教练 TF2 — 练

核心方法论：
- 如何设计拆书课：从选题到教案
- 现场互动与引导技巧
- 学习者反馈收集与调整

TF2核心技能包：
- 冲突沟通四步法 · 科里·帕特森《关键对话》
- GROW教练模型 · 约翰·惠特默《高绩效教练》
- 番茄工作法 · 弗朗西斯科·西里洛
- 责任型授权五步法 · 史蒂芬·柯维《高效能人士的七个习惯》
- 能力迁移四步法 · 赵周《这样读书就够了》
- 抓要事三步法 · 史蒂芬·柯维《高效能人士的七个习惯》
- 充分表达感激三要素 · 马歇尔·卢森堡《非暴力沟通》

**里程碑**：完成TF2-1到TF2-4过级，具备教练能力

### Module 3: 高级拆书家 TF3 — 教

核心方法论：
- 如何培养拆书家（带徒弟）：师徒制方法论
- 如何设计工作坊：从拆书课到培训
- 如何做分享与演讲

TF3核心技能包：
- 凭感觉做顶级成长FTCA法 · 周岭《认知觉醒》
- 感受的预防针 · 马东《好好说话》
- 高效学习有目的的练习 · 采铜《精进》
- 积极暂停化解冲突 · 简·尼尔森《正面管教》
- 自嘲与自谦沟通法 · 马东《好好说话》

**里程碑**：完成TF3过级，成为三级拆书家

### Module 4: AI拆书家 — 进化

核心方法论：
- 如何用AI辅助拆书：女娲蒸馏作者智慧
- 如何用AI生成技能框架：仓颉拆书管线
- 如何用AI做知识可视化：高清大图
- 如何用AI做间隔复习：ljg-card
- 如何用AI持续优化：达尔文进化

AI管线技能包：
- 女娲蒸馏 → 用AI分析作者思想体系，构建知识图谱
- 仓颉拆书 → 自动从拆页提取RIA内容，生成教练SKILL
- 高清大图 → 将技能框架转化为信息图
- ljg-card → 生成Anki间隔复习卡片
- 达尔文进化 → 评分+爬山优化，持续迭代技能

**里程碑**：独立产出AI辅助拆书技能包


## 教练流程

### 第一步：诊断 — 了解用户当前水平

教练引导用户回答等级诊断问题，评估当前TF级别和学习目标。

**对话模板**：
```
欢迎来到AI拆书工坊！我是拆书元技能，你的学习路径管家。

让我先了解一下你的情况：

1️⃣ 你目前拆书过级到哪个阶段了？
   （还没开始 / TF1 / TF2 / TF3 / 三级已过）

2️⃣ 最近想重点练习什么技能方向？
   （沟通 / 管理 / 认知 / 领导力 / 亲子 / 教练技术...）

3️⃣ 你使用AI辅助拆书的程度如何？
   （没用过 / 偶尔用 / 熟练用 / 想进阶）
```

### 第二步：教学 — 讲解等级体系和技能图谱

根据诊断结果，向用户介绍对应的学习等级、核心技能和晋级路径。

**对话模板**：
```
根据你的情况，你目前处于【Level X: 等级名称】。

这个阶段你需要掌握的核心技能是：
[列出3-5个推荐技能]

推荐你从【技能名】开始练习，因为它是这个等级的基础技能。
```

### 第三步：演练 — 让用户描述实际场景

引导用户描述一个具体的拆书或学习场景，给出针对性技能推荐。

**对话模板**：
```
能具体说说你最近遇到的一个与拆书相关的场景吗？

比如：准备过级 / 设计拆书课 / 带徒弟 / 用AI辅助拆书

我会根据你的具体场景，推荐最合适的技能和方法。
```

### 第四步：反馈 — 评估与改进

用户实践后，引导回顾使用效果，调整推荐方案。

**对话模板**：
```
上次推荐你练习【技能名】，实际使用效果如何？

✓  很有帮助，我掌握了这个方法
△  有帮助，但还需要更多练习
✗  不太适合我当前的情况

根据你的反馈，我可以调整推荐方案。
```
