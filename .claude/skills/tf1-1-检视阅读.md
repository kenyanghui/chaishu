# /检视阅读 · 教练技能

基于 赵周《这样读书就够了》的教练技能。
拆书家：大大-汤圆



## 核心方法论

### What — 这是什么

**/检视阅读** 是关于「/检视阅读」的实用技能。成人学习的核心不是"学了多少"，而是"用了多少"。拆书帮RIA便签法的本质就是"把知识转化为能力"。
### Why — 为什么重要

成人学习最大的痛点是"学完就忘、学了没用"。RIA便签法解决了这个问题：R（阅读）→ I（理解重述）→ A（关联应用），形成一个完整的学习闭环。没有A的学习只是信息消费，有A的学习才是真正的能力构建。
### How — 操作步骤

  1. **明确目标**：确定要学习的技能或知识的"够用标准"，而非追求完美
2. **分解技能**：将目标技能拆解为可练习的子技能和关键动作
3. **刻意练习**：针对薄弱子技能进行大量有反馈的重复练习
4. **反思内化**：将练习经验与现有知识体系整合，形成自己的方法论
### Where — 适用场景

「/检视阅读」属于 **学习与成长** 领域的核心技能。

**关联技能（同一书籍来源）：**
- `tf2-3-能力迁移四步法` — 能力迁移四步法
- `tf2-2-拆书七步曲` — 拆书七步曲

建议将同书技能组合学习，形成系统化的 学习与成长 能力框架。

**延伸阅读：**
参见学习与成长领域的其他技能，与本技能配合使用效果更佳。同时推荐了解学习与成长领域的基础方法论和进阶技巧，构建完整的知识体系。

**对比分析：**
理解「/检视阅读」的关键在于与其他方法的对比：

| 对比维度 | 被动学习 | 主动学习 |
|---------|---------|---------|
| **学习方式** | 阅读、听课、看视频 | 实践、讨论、教授他人 |
| **信息留存率** | 10%-30%（一周后） | 50%-90%（一周后） |
| **核心动作** | 接收、记忆 | 应用、反思、输出 |
| **学习动机** | 外部驱动（考试/任务） | 内在驱动（成长需要） |

被动学习是"信息消费"——感觉学到了很多，实际留存甚少。主动学习是"能力构建"——过程辛苦但效果持久。拆书帮RIA便签法本质上就是把被动阅读转化为主动学习的过程。

**跨领域连接：**学习与成长能力需要与以下领域协同发展：
认知思维（元认知能力）、效能与时间管理（学习时间规划）

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「/检视阅读」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「《这样读书就够了》/检视阅读」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（学习与成长方向）：**

A. **新技能入门** — 回想一个你最近遇到的新技能入门场景，用今天学到的「/检视阅读」方法重新思考如何应对

B. **读书拆解** — 回想一个你最近遇到的读书拆解场景，用今天学到的「/检视阅读」方法重新思考如何应对

C. **技能精进** — 回想一个你最近遇到的技能精进场景，用今天学到的「/检视阅读」方法重新思考如何应对

D. **知识体系构建** — 回想一个你最近遇到的知识体系构建场景，用今天学到的「/检视阅读」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「/检视阅读」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「/检视阅读」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「/检视阅读」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「/检视阅读」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
