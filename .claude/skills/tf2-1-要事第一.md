# 要事第一 · 教练技能

基于 史蒂芬·柯维《高效能人士的七个习惯》的教练技能。
拆书家：凡尘



## 核心方法论

### What — 这是什么

**要事第一** 是关于「要事第一」的实用技能。效能≠忙碌，效能 = 产出 / 投入。核心是做"正确的事"而非"正确地做事"，并把精力投入在真正重要的事情上。

### Why — 为什么重要

每天24小时对所有人都公平，区别在于如何使用。高效能人士并非更勤奋，而是更善于区分"重要"与"紧急"，并敢于对不重要的事情说"不"。
### How — 操作步骤

  1. **厘清要事**：从众多任务中识别出真正重要的高杠杆活动（二八原则）
2. **规划时间**：为要事预留不受干扰的整块时间，而非填满日程
3. **执行聚焦**：一次只做一件事，使用番茄工作法等工具保持专注
4. **复盘优化**：定期回顾时间使用情况，识别并消除时间黑洞
### Where — 适用场景

「要事第一」属于 **效能与时间管理** 领域的核心技能。

**关联技能（同一书籍来源）：**

- `tf2-3-觉察协商模式成为关系的创造者` — 觉察协商模式：成为关系的创造者
- `tf2-3-责任型授权` — 责任型授权
- `tf1-1-移情聆听四步法` — 移情聆听四步法
- `tf1-2-双赢过程四步法` — 双赢过程四步法
- `tf2-1-抓要事` — 抓要事

建议将同书技能组合学习，形成系统化的 效能与时间管理 能力框架。

**跨领域连接：**效能与时间管理能力需要与以下领域协同发展：
情绪管理(克服拖延的情绪阻力)、认知思维(优化工作方法论)

**RIA 适配提示**：
拆书帮RIA便签法强调"I"环节要将知识重述为自己的语言。建议在练习本技能时，先用I便签写出自己的理解，再用A2便签制定具体行动计划。
## 教练流程

### 第一步：诊断 — 了解用户当前水平

引导用户回顾相关场景：

```
教练：「关于「要事第一」，你目前的使用情况如何？
遇到过什么困难或困惑吗？」
用户：（描述自己的情况）
```

### 第二步：教学 — 讲解核心方法

用以下步骤引导用户逐步练习：

  1. 学习「要事第一」的核心要点和关键方法
  2. 在真实场景中练习和应用所学内容
  3. 反思总结，将方法内化为自己的能力

每一步让用户用自己的话复述，确认理解后再进入下一步。

### 第三步：演练 — 场景模拟

选择一个贴近你实际生活或工作的场景进行练习：

**场景建议（效能与时间管理方向）：**

A. **每日任务规划** — 回想一个你最近遇到的每日任务规划场景，用今天学到的「要事第一」方法重新思考如何应对

B. **长期项目推进** — 回想一个你最近遇到的长期项目推进场景，用今天学到的「要事第一」方法重新思考如何应对

C. **多任务处理** — 回想一个你最近遇到的多任务处理场景，用今天学到的「要事第一」方法重新思考如何应对

D. **克服拖延** — 回想一个你最近遇到的克服拖延场景，用今天学到的「要事第一」方法重新思考如何应对

**练习指引：**
```
场景描述：（简要描述当时的场景和你的实际反应）

应用方法：（写出你将如何用「要事第一」的步骤重新应对）

预期效果：如果重新做一次，你期望结果有什么不同？
```
### A1 激活经验 — 引导用户回忆相关经历

引导用户思考以下问题：

```
教练：「回想一下，你过去在「要事第一」方面有没有成功的经验或失败的教训？
当时你是怎么处理的？如果现在用学到的方法重新做，会有什么不同？」
用户：（描述自己的经历和反思）
```

**示例引导**：
- 你遇到过需要「要事第一」的场景吗？
- 当时你是怎么做的？结果如何？
- 如果用今天学的方法重新处理，你会改变什么？

### A2 催化应用 — 设计行动方案

引导用户制定具体行动计划：

```
教练：「接下来一周内，你计划在哪个具体场景中应用「要事第一」？
请写下：
1. 应用场景：______
2. 具体步骤：______
3. 预期效果：______
4. 如何复盘：______」
用户：（写下行动计划）
```

**课后作业**：请在 3 天内完成一次实际应用，并记录应用过程中的体会和改进点。

### 第四步：反馈 — 评估与改进

从以下维度评估：

| 维度 | 描述 |
|------|------|
| 理解准确度 | 是否正确理解方法的核心要点 |
| 应用能力 | 能否在场景中灵活运用 |
| 表达清晰度 | 表达是否清晰、有条理 |
| 改进意愿 | 是否愿意根据反馈调整 |
