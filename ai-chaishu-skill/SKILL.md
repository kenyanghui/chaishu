# AI拆书工坊 · 从一本书到一套技能体系

> **核心信念**：每见到一本书的拆页，就产出一个可用的教练 Skill。
>
> **一句话**：这是经过 69 本书、147 个技能实战验证的 AI 拆书管线——输入一本致用类书籍，输出一套可运行的教练技能体系 + 展示网站。

## 🧠 核心方法论

### 核心理念：输出倒逼输入

传统读书方式：读完 → 划线 → 忘记 ❌

AI 拆书工坊的方式：
```
打开一本书
  ↓
提取拆页（R：阅读原文片段）
  ↓
内化解读（I：用自己的话重新表达）
  ↓
设计应用（A：催化为可执行技能）
  ↓
产出 SKILL.md + 信息图 + 网站 ✨
  ↓
别人能用、能搜、能学
```

## 💻 技术实现深度拆解

### 1. 数据层：hotBooks.js

拆书帮的拆页数据统一存储在 `src/data/hotBooks.js`：

```javascript
// 数据结构示例
const hotBooks = [
  {
    title: '高效能人士的七个习惯',
    author: '史蒂芬·柯维',
    category: '管理领导',
    sessions: [
      {
        title: '移情聆听',
        rias: [{
          r: '原文片段...',              // Reading
          i: '内化解读...',              // Interpretation  
          a: '催化应用...',              // Appropriation
          level: 'TF1-1',               // 拆书过级等级
        }]
      }
    ]
  }
]
```

**数据规模**：69 本书 × 平均每本 2-3 场拆书 = 156 场拆书活动。

### 2. 管线层：pipeline-cangjie.js

这是核心引擎。它做的事情：

```
拆页原始 JSON
  ↓
解析 RIA 结构
  ↓
智能提取 What/Why/How/Where（支持 20+ 种格式变体）
  ↓
构建 SKILL.md（frontmatter + 方法 + 流程 + 出处）
  ↓
更新 skills.js（网站数据源同步）
  ↓
✅ 147 个 SKILL.md 自动生成
```

**技术亮点**：
- 正则引擎支持 20+ 种 RIA 格式变体（`【what】`、`(**What)**`、`**What**`、`What:` 等）
- 自动识别 TF 等级（TF1-1 ~ TF3-3），用于学习路径分类
- 从 prologue/learnGoal 自动提取学习目标和技能名称
- 从 explains 全文提取编号步骤（不局限于【how】段）

### 3. 展示层：React SPA

**6 个主要路由 + 50+ 组件**：

| 路由 | 页面 | 核心功能 |
|------|------|----------|
| `/` | 首页 | 数据总览、学习入口、成长之路导航 |
| `/hot` | 热门拆书 | 21 本书按分类展示，点击查看拆页详情 |
| `/skills` | 技能工坊 | **搜索框实时过滤** + TF1/TF2/TF3 标签筛选 + 计数显示 |
| `/learning-path` | 学习路径 | 四级递进：TF1→TF2→TF3→S级，点击跳转自动筛选对应等级技能 |
| `/hd-gallery` | 高清大图 | 7 大分类 + AI 封面图 + 网格浏览 |
| `/skill-fusion` | 技能融合 | 8 个思想体系 + 6 个融合包，支持直接下载 |

**技术特性**：
- SPA 单页应用，客户端路由（React Router）
- Framer Motion 动画过渡
- Tailwind CSS 暗色主题
- 搜索 0.1 秒出结果（前端 useMemo 缓存）
- 响应式设计（手机/平板/桌面）

### 4. AI 能力整合

| AI 能力 | 用途 | 效果 |
|---------|------|------|
| Claude Code | 主力开发环境 | 完成 95% 的代码编写和重构 |
| mxai API (seedream-5.0-pro) | 生成 2K 高清封面图 | 7 大分类封面 + 示例技能封面 |
| `达尔文` Skill | 对 SKILL.md 评分和优化 | 完整性/可执行性/引导性三维评分 |
| 本 Skill（AI拆书工坊） | 统筹整条管线 | 诊断→推荐→生成→展示→进化 |

## 📝 教练流程

当用户调用本 Skill 时，按以下流程引导：

### 第一步：诊断 — 了解用户需求

```
🎓 欢迎来到 AI 拆书工坊！

请告诉我：
1️⃣ 你想拆哪本书？（书名 + 作者）
2️⃣ 你目前是拆书新手还是有经验的拆书家？
   （零基础 / 正在过级 / 三级拆书家 / AI拆书家）
3️⃣ 你希望产出什么？
   （只想看技能 / 要信息图 / 要完整网站 / 想自己搭建）
```

### 第二步：匹配 — 选择执行路径

| 用户类型 | 推荐路径 |
|----------|----------|
| 零基础 | 先介绍 RIA 拆书法 → 演示一个完整案例 → 引导上手 |
| 正在过级的拆书家 | 按 TF 等级推荐技能 → 引导使用搜索功能 → 推荐学习路径 |
| 三级拆书家 | 介绍 AI 管线 → 演示女娲蒸馏 → 引导转型 AI 拆书家 |
| 想搭建自己的拆书网站 | 从数据准备到部署的全流程指导 |

### 第三步：执行 — 运行管线

根据用户选择的路径，执行对应的管线步骤：

```bash
# 如果用户有 RIA 拆页数据
node scripts/pipeline-cangjie.js   # 拆页 → SKILL.md
node scripts/update-skills.js      # 更新网站数据
npm run dev                        # 本地预览

# 如果用户需要信息图
node scripts/pipeline-hd-image.js  # SKILL.md → HTML 信息图

# 如果用户准备部署
npm run build                      # 构建
git push                           # 自动部署到 GitHub Pages
```

### 第四步：交付 — 输出成果

向用户交付完整的成果包：

```
📦 你的拆书成果包
├── 📁 .claude/skills/          → N 个教练 SKILL.md
├── 📁 public/images/skills/     → N 张 HTML 信息图
├── 🌐 本地预览                  → http://localhost:5173
└── 🚀 线上地址                  → https://your-username.github.io/chaishu/
```

## 🔧 自己搭建：从零开始部署

### 前置条件
```bash
node -v  # 需要 18+
npm -v   # 需要 9+
git --version
```

### 一键初始化

```bash
# 1. 克隆模板
git clone https://github.com/kenyanghui/chaishu.git my-chaishu
cd my-chaishu

# 2. 安装依赖
npm install

# 3. 准备你的拆书数据
# 编辑 src/data/hotBooks.js，替换成你自己的拆书拆页

# 5. 本地预览
npm run dev

# 6. 构建部署
npm run build
git add -A && git commit -m "我的拆书网站"
git push
```
