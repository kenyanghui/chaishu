# 投资决策融合包

> 融合巴菲特 + 芒格 + 段永平 + 缠论
> 构建从企业分析到市场操作的完整投资决策链

---

## 包含技能

### 1. 能力圈判断（巴菲特）
**核心问题：** 你真的理解这个领域吗？

**关键要点：**
- 能力圈大小不重要，重要的是知道边界在哪
- 能力圈由历史判断准确率定义，而非熟悉程度
- 在圈外犯错可能是灾难性的

**使用方法：** 对每个投资标的，先问"我真的理解这家企业怎么赚钱的吗？"

### 2. 经济护城河分析（巴菲特）
**核心问题：** 这家企业的竞争优势能持续多久？

**关键要点：**
- 真正的好企业必须有持久的竞争优势
- 护城河来源：品牌、转换成本、网络效应、成本优势、规模优势

**使用方法：** 识别企业的护城河类型并评估其可持续性

### 3. 双轨分析（芒格）
**核心问题：** 理性分析与心理因素分别告诉我们什么？

**关键要点：**
- 第一轨：理性分析——企业的基本面和估值
- 第二轨：心理因素——市场情绪和认知偏误

**使用方法：** 分别做理性估值和心理诊断，再做综合决策

### 4. 人类误判心理学检查清单（芒格）
**核心问题：** 我们陷入了哪些认知偏误？

**关键要点：**
- 25种认知偏误的系统检查
- 特别关注：过度乐观、确认偏误、社会认同

**使用方法：** 重大决策前跑一遍检查清单

### 5. 投资逻辑框架（段永平）
**核心问题：** 做对的事，把事情做对

**关键要点：**
- 做对的事：不做什么比做什么更重要（Stop Doing List）
- 把事情做对：本分、平常心、敢为天下后

**使用方法：** 用不为清单排除坏机会，对好机会集中投入

### 6. 缠论买卖点判定（缠论）
**核心问题：** 当前市场结构下，买卖点出现了吗？

**关键要点：**
- 第一类买点：趋势背驰后的反转点
- 第二类买点：回踩不创新低的确认点
- 第三类买点：突破中枢后的回踩点

**使用方法：** 用买卖点信号确认入场/出场时机

---

## 使用流程

```
1. 用能力圈判断 → 排除不懂的领域
2. 用护城河分析 → 识别好企业
3. 用双轨分析 → 做理性估值+心理诊断
4. 用心理学清单 → 排除认知偏误
5. 用不为清单 → 排除坏机会
6. 用缠论买卖点 → 确认入场时机
```
