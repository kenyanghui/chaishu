# 系统诊断融合包

> 融合黄帝内经 + 毛选矛盾分析 + 第一性原理
> 从多维度诊断系统问题

---

## 包含技能

### 1. 阴阳平衡分析（黄帝内经）
**核心：** 诊断系统对立面的失衡状态

### 2. 五行生克网络（黄帝内经）
**核心：** 分析系统元素间动态关系

### 3. 标本缓急决策（黄帝内经）
**核心：** 区分根本原因vs表面现象的优先级

### 4. 传变预测模型（黄帝内经）
**核心：** 推演系统连锁反应和扩散路径

### 5. 矛盾分析法（毛泽东选集）
**核心：** 识别主要矛盾和矛盾的主要方面

### 6. 还原论解构（第一性原理）
**核心：** 将复杂系统解构至不可再分的基本元素

## 使用流程

```
1. 阴阳平衡 → 分析系统对立面状态
2. 五行网络 → 画出系统元素关系图
3. 矛盾分析 → 找出主要矛盾
4. 还原论 → 解构至基本单元
5. 标本缓急 → 确定优先级
6. 传变预测 → 推演干预后果
```
