# 战略分析融合包

> 融合毛泽东选集 + 第一性原理 + 孙-子兵法
> 构建顶层战略思维与执行框架

---

## 包含技能

### 1. 矛盾分析法（毛泽东选集）
**核心问题：** 复杂局面中的主要矛盾是什么？

**关键要点：** 任何复杂局面都由多个矛盾交织构成。找出那个决定其他矛盾的主要矛盾，就是战略的起点。

### 2. 调查研究法（毛泽东选集）
**核心问题：** 我们的判断有事实依据吗？

**关键要点：** 没有调查就没有发言权。一切结论产生于调查情况的末尾，而不是在它的先头。

### 3. 战略藐视与战术重视（毛泽东选集）
**核心问题：** 如何在战略与战术层面取得平衡？

**关键要点：** 战略上要藐视困难（坚信能赢），战术上要重视困难（做足准备）。二者缺一不可。

### 4. 公理化思维（第一性原理）
**核心问题：** 这个领域不可动摇的基石假设是什么？

**关键要点：** 从少数几条不证自明的公理出发，通过演绎法推导整个战略体系。

### 5. 隐含假设挖掘（第一性原理）
**核心问题：** 我们的战略建立在哪些未言明的假设上？

**关键要点：** 识别那些"不言自明"的隐含假设，往往是突破战略瓶颈的关键。

### 6. 孙子兵法竞争策略（知本创业法）
**核心问题：** 不战而屈人之兵，上之上策也。

**关键要点：** 知彼知己、避实击虚、以正合以奇胜。

---

## 使用流程

```
1. 矛盾分析 → 识别战略焦点
2. 调查研究 → 验证判断
3. 公理化思维 → 建立战略推导链
4. 隐含假设挖掘 → 识别盲区
5. 孙子兵法 → 制定竞争策略
6. 战略藐术重视 → 执行落地
```
