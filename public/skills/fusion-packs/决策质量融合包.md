# 决策质量融合包

> 融合芒格 + 第一性原理 + 巴菲特 + 段永平
> 打造高质量决策流水线

---

## 包含技能

### 1. 检查清单决策法（芒格）
**核心：** 用结构化清单确保不遗漏关键因素

### 2. 逆向思维（芒格）
**核心：** 反过来想——如果目标是搞砸，你会怎么做？然后避开这些事。

### 3. 激励机制分析（芒格）
**核心：** 识别决策背后真正的激励因素

### 4. 批判性思维（第一性原理）
**核心：** 系统地质疑每一个假设

### 5. 逻辑三洽检验（第一性原理）
**核心：** 自洽、他洽、续洽三重逻辑验证

### 6. 安全边际（巴菲特）
**核心：** 始终留足容错空间

### 7. 商业逻辑框架（段永平）
**核心：** 回归商业本质做判断

## 使用流程

```
1. 商业逻辑 → 判断这是不是一个好生意
2. 批判性思维 → 质疑假设
3. 逻辑三洽 → 检验推理链
4. 激励机制 → 分析真实的驱动力
5. 逆向思维 → 排除最坏情况
6. 检查清单 → 确保全面
7. 安全边际 → 留足缓冲
```
