## 导入 Anki 方法

1. 打开 Anki → 文件 → 导入
2. 选择 CSV 文件
3. 字段分隔符：逗号
4. 导入选项：
   - 字段 1: 技能名 (忽略)
   - 字段 2: 卡片类型
   - 字段 3: 正面 (正向)
   - 字段 4: 背面 (反向)
   - 字段 5: 标签
   - 字段 6: 出处 (忽略)
5. 点击导入
