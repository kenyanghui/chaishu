备开始之前：设备与账号自查

主线用电脑（Win/Mac 通用）；只有手机也给了完整降级路径。两个工具都免费：ima（腾讯的个人知识库）+ WorkBuddy（AI 工作流，www.workbuddy.cn）。本期所有 WorkBuddy 操作都是把写好的话复制给它——全程说人话，不需要懂任何技术词。

你需要有怎么确认已有没有怎么办
ima（电脑客户端或手机 App）ima.qq.com 下载，微信扫码登录；设置 → 开放 API 里领好 Client ID / API Key纯手机：App 商店搜 ima 同样能完成建库节
WorkBuddy 账号浏览器打开 www.workbuddy.cn 能登录没有：第 3 节带你注册（免费）
（可选）微信公众号mp.weixin.qq.com 后台能进；设置与开发 → 基本配置里记下 AppID、生成 AppSecret没有个人公众号：第 3 节出口 B 换成「导出到备忘录」，流程一样
3–5 份你自己的资料笔记/拆页/讲课稿/收藏的文章都算没准备：手机拍 2 张你写过的便签也算数，先跑通再加料
「只有手机」的同学：第 1–2 节（建库）手机完成没问题；第 3 节（WorkBuddy 工作流）手机浏览器也能发指令，但建议借电脑 40 分钟体验更顺。中途无论出什么错，统一动作：把报错原话发回给 WorkBuddy，说「请修好后继续」。

1第 1 节 · 存：让 AI 记住你（ima 建库）

本节目标：建一个你自己的知识库，导入 3–5 份资料并打标签｜预计 30 分钟

动手前确认：ima 已登录；3–5 份资料在手边（手机相册/电脑文件夹）。
新建知识库，起个你记得住的名字
  • ima 里点「知识库」→ 新建
  • 库名建议带你的名字（如「阿珍的弹药库」）——以后会有第二个第三个库，别叫「我的库」
电脑ima 客户端左侧栏「知识库」→「+」新建
手机ima App 底部「知识库」→ 右上角「+」
检查点（看到才算做对）：库里空空但已经存在，名字是你起的
没看到怎么办：找不到新建入口：更新 ima 到最新版；入口一般在知识库页右上角
建 2–3 个分类（按「你下次会怎么找」分）
  • 在库里建文件夹/分类，参考一个拆书家的库：
  • ① 指令案例集：用得好用的 AI 指令、成功案例、踩坑记录
  • ② 话术库：开场/提问/收尾/点评，你实际说过的好句子
  • ③ 素材库：能拆能写的原材料
  • 分几类不重要，重要的是你闭眼知道东西在哪
检查点（看到才算做对）：库里有了 2–3 个分类
没看到怎么办：纠结怎么分：先按上面三个抄，用两周后再改——分类是长出来的不是想出来的
导入 3–5 份资料
  • 把资料拖进对应分类（或先全部进默认区再分）
  • 支持的格式：PDF/Word/图片/Markdown/txt 都行；纸质资料拍照导入
  • 手机拍的便签照片直接上传也算
电脑直接拖文件进 ima 窗口最省事
手机App 里「+」→ 从相册选/拍照/选文件
检查点（看到才算做对）：库里有 3–5 份资料，点开能看到内容
没看到怎么办：导入失败：单个文件损坏或格式太老，换个格式（如 doc 转 docx）再传；图片糊了重拍
给至少 2 份资料打标签
  • 标签和分类的区别：分类是抽屉（放一处），标签是便利贴（贴多个）
  • 例：一份「开场话术」素材，分类放话术库，标签可以同时打「开场」「培训」「2026」
  • 标签打完，以后搜索一击即中
检查点（看到才算做对）：≥2 份资料有标签，且你能说出为什么打这个标签
没看到怎么办：不会打标签：就打「什么时候会用它」，如「讲课前翻」
问它一句：验收你的库
  • 对 ima 的 AI 问答问一个只有你资料里有答案的问题
  • 例：「我的开场话术里最适合破冰的是哪句？」
  • 它能引用你刚导入的资料回答 = 库已生效
检查点（看到才算做对）：AI 回答引用了你的资料（回答里带资料来源）
没看到怎么办：答不上来：资料刚导入还在解析，等 5–10 分钟再问；图片类资料解析慢属正常

本节排障表（4 个常见卡点）

症状可能原因解法
ima 登录不上网络/授权问题切流量；退出重登；换微信授权试一次
导入一直转圈文件大/格式问题换小文件先试；PDF 超大就拆分后再传
AI 答非所问资料还没解析完/问法太泛等 10 分钟；问题带上资料里的关键词，如「开场」
手机 App 闪退版本旧/内存不足更新 App；清后台重开

2第 2 节 · 理：让库变成弹药（整理与提问套路）

本节目标：学会两招：喂料时一句话标注、用时三个提问模板｜预计 25 分钟

动手前确认：库里有料（第 1 节完成）。
给旧资料补「一句话标注」
  • 每份资料的标题或开头，补一句话：给谁用/什么时候用/好在哪
  • 例：「给新经理｜绩效面谈前翻｜先问后评不炸毛」
  • AI 检索时这句话就是它的路标
检查点（看到才算做对）：≥3 份资料有一句话标注
没看到怎么办：写不出「好在哪」：写「我用它解决过__」也算
练三个提问模板
  • 对 ima AI 各问一遍，体会差别：
  • ① 检索型：「我的库里关于__的资料有哪些？」
  • ② 提炼型：「把库里关于__的要点合成一段话」
  • ③ 应用型：「我要__（场景），从库里帮我找可用的素材并给出组合建议」
  • 第三种最值钱——它把库变成了参谋
检查点（看到才算做对）：三个模板各问过一次，至少一个回答让你觉得「有用」
没看到怎么办：回答空泛：给提问加限定词（字数/受众/口吻），如「合成一段 100 字内、给小白看的」
定「随手存」的规矩
  • 在手机备忘录写一行规矩：从今天起，看到好内容 10 秒内转存 ima
  • 入口：微信文章右上角「⋯」→ 更多打开方式 → ima（或复制链接在 ima 里粘贴）
  • 库是存出来的，不是整理出来的
检查点（看到才算做对）：规矩已写+今天已存 ≥1 条新内容
没看到怎么办：微信转存入口没有：先复制链接，打开 ima 粘贴链接也能存

本节排障表（3 个常见卡点）

症状可能原因解法
提问没回应当日额度/网络切流量；第二天再试（免费额度每日刷新）
检索结果不准标注缺失回到第 1 步补标注；检索词用标注里的原词
微信文章存不进入口未配置用复制链接→ima 粘贴的方式，一定行

3第 3 节 · 用：三句话，跑通公众号产线（WorkBuddy）

本节目标：复制三句话发给 WorkBuddy，凭证贴在冒号后——产线跑起来，文章进草稿箱｜预计 60 分钟

动手前确认：已登录 www.workbuddy.cn；「开工前三件事」的钥匙已领到手（ima 的 API Key + Client ID、公众号的 AppID + AppSecret）。
注册并登录 WorkBuddy（已有跳过）
  • 浏览器打开 www.workbuddy.cn
  • 注册（手机号/微信均可，免费）→ 登录进主界面，能看到对话框
  • 本期你只需要会四件事：复制、粘贴、把凭证贴在冒号后、发送
检查点（看到才算做对）：对话框能输入文字、能收到回复
没看到怎么办：打不开：换浏览器（Chrome/Edge）；验证码收不到等 60 秒重发
指令①：接 ima 知识库
  • 复制这句，贴进 WorkBuddy 对话框，把你领的钥匙贴在冒号后，发送：
  • 「接ima知识库，API Key和Client ID是：」
  • 钥匙还没领：ima.qq.com → 设置 → 开放 API → 开通，把 API Key 和 Client ID 复制存好（手机备忘录即可）
  • WorkBuddy 说通了、能报出你的库名 = 接上了
检查点（看到才算做对）：WorkBuddy 回复能读到你的知识库（库名对得上）
没看到怎么办：说钥匙不对：回 ima 开放 API 页重抄一遍——API Key 容易复制少字符，逐字核对
指令②：接微信公众号
  • 复制这句，凭证贴在冒号后，发送：
  • 「接微信公众号，AppID和AppSecret是：」
  • 凭证还没领：mp.weixin.qq.com → 设置与开发 → 基本配置 → 记下 AppID、生成 AppSecret（只显示一次，立刻存好）；同一页把本机 IP 加入白名单
  • 暂不注册公众号也行：跳过这句，指令③走本地 HTML 出口，流程一样
检查点（看到才算做对）：WorkBuddy 回复凭证可用
没看到怎么办：报 IP 不在白名单：按它给出的本机 IP，回公众号 基本配置 页加入白名单，再发一遍「再试一次」
指令③：装技能，跑一次
  • 复制这句，直接发送（这句不用填任何东西）：
  • 「安装github.com/kenyanghui/rsi-ima-workbuddy-wechatpub，跑一次工作流」
  • 它会自己装技能、自己跑完一整圈：取素材 → 出稿 → 质检 → 进你的公众号草稿箱，等它干完
  • 跑完去 mp.weixin.qq.com 草稿箱看：文章已躺在那，群发与否你定——发布这道闸门永远在你手里
检查点（看到才算做对）：公众号草稿箱（或本地 HTML 文件）里出现机器产出的文章，截图存档
没看到怎么办：中途报错：把报错原话发回，加一句「请修好后继续」；没配公众号 API 的走本地 HTML 出口，文章打包成 HTML 手动粘贴发布
把三句话存好
  • 三句话存进手机备忘录或 ima 库：①接ima知识库 ②接微信公众号 ③装技能跑一次
  • 以后每次换素材、换主题重跑：只发第三句就行——前两句接一次管长期
  • 这就是你的产线：一句话启动，人工只把关发布
检查点（看到才算做对）：备忘录里存了三句话
没看到怎么办：忘了哪句：回本手册页复制，或翻 WorkBuddy 聊天记录

本节排障表（5 个常见卡点）

症状可能原因解法
WorkBuddy 说钥匙/凭证不对复制少了字符/过期回对应官网页重抄一遍再发；API Key 和 AppSecret 都容易少尾巴，逐字核对
报 IP 不在白名单公众号侧未加白按 WorkBuddy 报的本机 IP，在公众号 设置与开发→基本配置 加入白名单，发「再试一次」
AI 没反应当日免费额度耗尽明天再跑（额度每日刷新）；跑产线放在当天第一件事，额度留给它
跑完草稿箱没文章出口走了本地 HTML没配公众号 API 时走本地 HTML 出口：找 WorkBuddy 要生成的 HTML 文件，手动粘贴发布
文章质量不满意初稿本来就是给人改的把要改的点告诉 WorkBuddy（如「第二段例子换掉」）；发布前自己过一遍是铁律

验全部做完：交付物自检表

逐项打勾，全勾 = 这场工作坊的成果你已真实拥有。建议每勾一项截一张图存相册，那就是你的完成凭证。

续30 天巩固计划（自助版）

工作坊的成果 30 天不用就会忘。每周一小步，周末 5 分钟自查没掉队。

时间做什么怎么自查没掉队
第 1 周存库周：每天随手存 ≥1 条进 ima（10 秒规矩）；本周库存 +7库新增 ≥7 条，全部有一句话标注
第 2 周产稿周：发第三句重跑 1 篇，人工校对后发布草稿箱 ≥2 篇、已发布 ≥1 篇署名稿
第 3 周发布周：选 1 篇真的发出去（公众号/朋友圈/星球都算）；收集 ≥3 条反馈回库存着1 篇已发布+反馈入库
第 4 周复盘周：算账——单次耗时 __ 分钟×每月 __ 次=一年约 __ 小时；定下月主题排期一张算账截图+下月排期表

1. 重读当前步骤的「检查点」和本节排障表——90% 的卡点都在里面；
2. 把你看到的界面截图保存下来，对照排障表找「症状」一栏；
3. 还不行：带上截图来微信群问，微信 ikoning365（点击不了就手动复制添加）。
