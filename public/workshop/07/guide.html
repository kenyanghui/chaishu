1第 1 节 · 认识 DSA：建好你的自选股清单

本节目标：进入工作台，认识八大模块，把 3–5 只自选股加进清单｜预计 40 分钟

动手前确认：浏览器能打开 http://39.108.95.179:8000，手边有访问密码。
打开 DSA 并登录
  • 浏览器访问 http://39.108.95.179:8000
  • 输入访问密码 AIBay666 进入工作台
检查点（看到才算做对）：看到深色界面首页，导航里有「个股分析」「问股」「大盘复盘」等入口
没看到怎么办：打不开：检查网址有没有多空格；再不行换 Chrome 或清除缓存重试；仍不行截图发群里
花 5 分钟逛一遍八大模块
  • 按顺序点一遍：首页·个股分析 / 问股 Agent / 大盘复盘 / 告警 / 回测 / 持仓 / 选股 / 设置+用量
  • 每个模块只看「它能干什么」，不用细研究参数
  • 记一句：输入代码出报告 → 问股管多轮问答 → 复盘管大盘 → 告警管盯梢
检查点（看到才算做对）：八个入口都点开过，能说出每个模块一句话用途
没看到怎么办：入口位置变了：以页面导航实际为准，功能名基本不变
建自选股清单：加 3–5 只你的股票
  • 找到自选股管理入口，逐个输入 6 位代码添加
  • 没想好就先加演示码：600519 贵州茅台、000858 五粮液、300750 宁德时代、600036 招商银行
  • 清单里确认代码和名称对得上号
检查点（看到才算做对）：自选股清单里至少 3 只，代码-名称一一对应
没看到怎么办：搜不到代码：确认是 6 位 A 股代码（0/3/6 开头）；名称对不上：看是否输错位
顺手看一眼 K 线与用量
  • 点开清单里任意一只，看它的 K 线历史数据能不能显示
  • 进「设置+用量」看 LLM token 消耗监控界面，确认用量在正常范围
检查点（看到才算做对）：K 线能显示；用量页有 token 数字且数值不大
没看到怎么办：K 线空白：可能是非交易时段数据未加载，刷新一次；用量异常大：别再批量提交任务，发群里问讲师

2第 2 节 · 跑通个股分析 + 大盘复盘 + 告警规则

本节目标：出第一份个股分析报告并导出；跑一次大盘复盘；建一条告警规则｜预计 45 分钟

动手前确认：第 1 节自选股清单已建好，浏览器会话没掉。
跑一份个股分析报告
  • 进「首页·个股分析」，输入清单里你最关心的一只代码
  • 提交后注意：分析是异步任务——提交后会排队，等它跑完再看结果
  • 报告出来后通读一遍：基本面、技术面、AI 建议、风险观察条件各在讲什么
检查点（看到才算做对）：拿到一份完整分析报告，AI 建议和风险观察条件两块都能看到
没看到怎么办：任务一直排队：token 用量可能紧张，稍等几分钟；报告字段缺失：换 600519 再跑一份对照
导出报告并存档
  • 找到历史报告列表，选中刚才那份
  • 导出为 Markdown 文件，存到本地一个专门文件夹（如 dsa-reports/）
  • 再试一次「分享图」导出，存一张图片版
检查点（看到才算做对）：本地文件夹里有 1 个 .md 文件 + 1 张分享图
没看到怎么办：导出按钮找不到：在报告详情页找「导出 / 分享」入口；下载没反应：换 Chrome 试
跑一次大盘复盘
  • 进「大盘复盘」，触发一次复盘任务（同样异步，等它跑完）
  • 通读复盘结论：市场整体温度、板块动向、风险提示
  • 用「问股 Agent」追问一句，例如「今天大盘为什么这样走？」验证多轮问答
检查点（看到才算做对）：拿到一份大盘复盘结论；问股 Agent 能就复盘内容多轮追问
没看到怎么办：复盘任务排队：同 s2-1，等几分钟；Agent 答非所问：把问题问得更具体（带上股票名或板块名）
建一条告警规则
  • 进「告警」模块，新建规则：选一只自选股，设一个条件（如涨跌幅超过阈值）
  • 开启通知，确认规则状态为「已启用」
  • 截图存档——这是交付 ② 的工作流凭证
检查点（看到才算做对）：告警列表里有 1 条「已启用」的规则，截图已存
没看到怎么办：条件不会设：先设最简单的涨跌幅阈值；通知不触发：非交易时段不触发属正常，交易日再验证

本节排障表（3 个常见卡点）

症状可能原因解法
分析任务一直转圈异步任务排队 / token 紧张等 3–5 分钟刷新；不要连续提交多只，一次跑一只
报告结论看不懂术语太多把报告关键段贴给问股 Agent，让它用大白话解释一遍
告警规则不触发阈值太宽 / 非交易时段阈值先设小一点验证链路；交易日盘中再确认通知

3第 3 节 · 持仓组合 + 30 天盯盘复盘计划

本节目标：建持仓组合快照，读懂风险分析；把 30 天盯盘复盘计划写满｜预计 35 分钟

动手前确认：第 2 节的个股报告与告警规则已就位。
建持仓组合快照
  • 进「持仓」模块，把你的真实或模拟持仓录进去（股票代码 + 大致仓位）
  • 不想暴露真实仓位：用演示自选股 12 只里的 4–5 只建一个模拟组合
  • 生成组合快照，看它给出的持仓结构与风险分析
检查点（看到才算做对）：组合快照已生成，能看到集中度 / 风险维度的分析结论
没看到怎么办：仓位数字不想填真的：按比例填（如 30/30/40），分析照样能跑
（可选）跑一次选股候选
  • 进「选股」模块，选一个策略跑出候选清单
  • 把 1–2 只候选加进自选，标记「候选」——只做研究，不等于买入指令
检查点（看到才算做对）：选股出了候选列表，至少 1 只已加进自选并标记
没看到怎么办：策略参数不会选：全部用默认值先跑通；记住候选仅供研究参考
写满 30 天盯盘复盘计划
  • 在笔记里按模板写三行承诺：每日（盘中看告警 2 分钟）/ 每周（大盘复盘 + 持仓快照各一次）/ 每月（复盘卡自查一次）
  • 给每行写上「完成标志」，能截图的写截图
  • 打印或贴电脑边——30 天后才算这套工作流是你的
检查点（看到才算做对）：30 天计划三行齐：每日 / 每周 / 每月，各有完成标志
没看到怎么办：节奏定不出来：先用手册的默认节奏（每日 2′/ 每周 15′/ 每月 30′），跑两周再调
