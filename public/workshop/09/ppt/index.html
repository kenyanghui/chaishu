为什么是量化——你踩过的坑，八成都在这

坑一

凭感觉买卖

"感觉要涨"就买了，买完跌了又说"长期持有"。量化把买卖规则先写清楚，规则不清楚就不下单。

坑二

赚亏说不清

赚了不知道为什么赚，亏了不知道为什么亏。回测报告三个数——总收益、最大回撤、交易次数——让盈亏有账可查。

坑三

策略没检验

听来的"必胜法则"直接上真钱。回测就是策略的体检：先在历史数据上跑一遍，再谈信不信。

正解

规则 + 检验

写清楚 → 跑回测 → 上模拟盘——一条完整流程走下来，判断才有依据。回测赚钱 ≠ 未来赚钱，这一页请记牢。

量化结果仅供学习研究，不构成投资建议；课堂只用模拟盘和历史数据

回测报告——抄下三个数，写三行结论

总收益

赚了多少

整个区间的收益率——看绝对数，也看曲线形状。

最大回撤

最疼的一跌

交易次数

出手几次

写三行：赚的时候怎么赚的 / 亏的时候怎么亏的 / 我信不信这个结果——报告存档 + 三行结论 = 交付②。
