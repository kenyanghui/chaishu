合规：全部量化结果仅供学习研究，不构成投资建议；课堂只用模拟盘和历史数据，不涉及任何真实资金操作。

开场 · 量化是什么

先建立地图，再动手——知道自己在流程的哪一站。

一句话：量化 = 把「什么时候买、买多少、什么时候卖」写成明确的规则，交给程序执行，再用数据检验这套规则行不行。QuantDinger 官方链路五站：AI research → Strategy code（Python 策略）→ Backtest（回测）→ Paper/Live execution（模拟盘/实盘执行）→ Monitoring（监控），self-hosted 一体化，覆盖 crypto、股票、外汇三大市场。今天我们只走到模拟盘。

课堂红线：所有结果仅供学习研究，不构成投资建议；只使用模拟盘和历史数据。回测赚钱 ≠ 未来赚钱，这一页请记牢。

1第 1 节 · 装起来：本地部署 QuantDinger

本节目标：Docker 自托管部署跑通，Web 界面打得开｜预计 45 分钟

动手前确认：电脑能上网，已安装 Docker Desktop（或同等 Docker 环境）；仓库地址 github.com/OpenByteInc/QuantDinger（官方提供简体中文 README，本站 Gitea 有镜像 Loong/QuantDinger）。
克隆仓库，翻一遍中文 README
  • 终端执行：git clone https://github.com/OpenByteInc/QuantDinger.git
  • 打开项目里的 README，切换到简体中文版，找到「部署 / 安装」章节
  • 顺手记住三件事：它是什么（AI Trading OS）、许可证（Apache-2.0）、覆盖市场（crypto / 股票 / 外汇）
检查点（看到才算做对）：本地多了 QuantDinger 目录，README 中文版能打开
没看到怎么办：GitHub 拉不动就换本站 Gitea 镜像 Loong/QuantDinger；或直接浏览器打开仓库页在线读 README
按官方 README 的 Docker 步骤启动
  • 安装步骤以官方 README 中文版为准（版本迭代快，不抄本手册的命令）
  • 确认 Docker 正在运行：docker ps 能列出容器
  • 照 README 里的 self-hosted 部署说明逐条执行，等镜像拉取、服务启动完成
检查点（看到才算做对）：README 中承诺的 Web 界面地址在浏览器里能打开
没看到怎么办：先看终端报错最后一行；端口占用就换个端口；内存不足就关掉大软件再启动；仍卡住截图发群里
逛一圈界面，认五张脸
  • 对应官方链路找到五个模块入口：AI research（研究）/ Strategy（策略）/ Backtest（回测）/ Paper execution（模拟盘）/ Monitoring（监控）
  • 每个模块点进去 30 秒，知道它大概放什么
  • 如果界面支持中文就切成中文
检查点（看到才算做对）：五个模块入口都点开过，截图一张全家福交组长
没看到怎么办：界面找不到某模块就回 README 的功能清单对照；docs/agent 里有 AI Agent/MCP 相关文档，顺手扫一眼即可，不强求

本节排障表（4 个常见卡点）

症状可能原因解法
git clone 超时网络到 GitHub 不稳改用本站 Gitea 镜像 Loong/QuantDinger；或浅克隆加 --depth 1
docker 命令不存在Docker 未装或未启动先装 Docker Desktop（Windows/Mac）或 docker-ce（Linux），装完重启终端
镜像拉取很慢/失败镜像源网络问题配置国内镜像加速器后重拉；或多次重试，断点会续传
Web 界面打不开服务未起完/端口被占看容器日志等启动完成；换端口重新启动；确认浏览器访问的是 README 写的地址

2第 2 节 · 写出来：AI 研究助手 + 第一个策略 + 回测

本节目标：用 AI 研究助手写出第一个 Python 策略并跑出回测报告｜预计 45 分钟

动手前确认：第 1 节部署的 QuantDinger 界面能正常打开。

打开 AI 研究助手，问三个入门问题
  • 「双均线策略的思路是什么？什么时候买、什么时候卖？」
  • 「回测里收益、最大回撤、胜率分别怎么看？」
  • 「帮我写一个最简单的双均线 Python 策略骨架」
检查点（看到才算做对）：助手给出一段能看懂的策略思路 + 一份 Python 策略骨架代码
没看到怎么办：问题拆小再问；或把 README 示例策略贴给助手让它逐行讲解
把策略放进 Strategy code 模块
  • 新建一个策略，把骨架代码填进去（策略文件命名、入口以官方文档为准）
  • 看懂三个关键件：入场条件（什么时候买）、出场条件（什么时候卖）、仓位大小（买多少）
  • 先跑一次语法/编译检查（有报错就把报错原样贴回给 AI 助手）
检查点（看到才算做对）：策略保存成功，没有红色报错
没看到怎么办：报错贴给 AI 研究助手让它改；通常是缩进、括号或缺少 import；还不行就用官方示例策略原样跑通再说
配置回测并跑第一次 Backtest
  • 选一个市场（crypto / 股票 / 外汇都可以，建议选数据最全的）
  • 设置回测区间（一段历史数据）、初始资金、手续费——按界面默认先跑通再改
  • 点击运行，等回测完成
检查点（看到才算做对）：回测完成，出现收益曲线和指标面板
没看到怎么办：历史数据未下载就先按提示下载；区间太长跑得慢就先缩到一年以内
读回测报告，写下三行结论（交付 ②）
  • 抄下三个数：总收益、最大回撤、交易次数（有胜率更好）
  • 写三行：赚的时候怎么赚的 / 亏的时候怎么亏的 / 我信不信这个结果
  • 导出或截图整份回测报告存档
检查点（看到才算做对）：回测报告已存档 + 三行结论已写，交组长
没看到怎么办：导出按钮找不到就整页截图；三行结论写不出来就把指标贴给 AI 助手让它解读，你只负责挑一句认同的抄下来

本节排障表（4 个常见卡点）

症状可能原因解法
AI 助手没响应模型服务未配置照官方文档（docs/agent 相关章节）检查 AI 配置；现场举手找讲师
策略保存报语法错代码骨架有笔误把完整报错贴回给 AI 助手，让它给出修正后的完整文件
回测一直转圈数据量大/区间太长缩短回测区间；确认历史数据已下载完成；看容器日志有无异常
指标面板空白回测未产生成交均线周期改小（如 5/20）让信号变多，重跑一次

3第 3 节 · 跑起来：模拟盘 + 监控 + 30 天计划

本节目标：策略上模拟盘、看懂监控面板、写完 30 天计划｜预计 35 分钟

动手前确认：第 2 节的策略已保存，回测报告已存档。记住：课堂只用模拟盘（Paper execution），不碰真实资金。
把策略部署到模拟盘（Paper execution）
  • 在模拟盘模块新建执行任务，选你刚写的策略
  • 市场与回测保持一致，虚拟资金按默认
  • 启动执行，确认状态变为「运行中」
检查点（看到才算做对）：模拟盘任务运行中，截图存档
没看到怎么办：启动失败看日志最后一行；数据源未连上就先按界面提示配置免费数据源；实在起不来，看讲师投屏演示版也算完成（截图自己的任务页）
打开 Monitoring 盯十分钟
  • 看三个东西：当前持仓 / 最近成交 / 权益曲线
  • 确认监控面板有数据在动（模拟行情推送正常）
  • 给自己设一条规则：每天只看两次监控，早上一次晚上一次——盯盘不产生收益
检查点（看到才算做对）：监控面板截图一张（含持仓或成交），存档
没看到怎么办：面板空白等几分钟让行情推进；模拟盘刚启动没成交是正常的，把策略的均线周期调小让信号更容易触发
写完 30 天量化学习计划（交付 ③）
  • 第 1 周：每天看懂一个回测指标（收益/回撤/胜率/夏普），跑通一次完整回测
  • 第 2 周：改一个策略参数对比回测结果，体会「过拟合」是什么
  • 第 3 周：换一个市场/标的再跑，记录差异
  • 第 4 周：让 AI 助手帮你加一个风控条件（如止损），回测对比并写一句结论
  • 用材料 04 的三栏表写满：哪天做 / 做什么 / 存哪里
检查点（看到才算做对）：30 天计划三栏写满，拍照或截图存档
没看到怎么办：抄上方四周模板先写满再改；写不动就只写第 1 周七天，其余带回家补

本节排障表（3 个常见卡点）

症状可能原因解法
模拟盘启动失败数据源/账户未配按界面提示配置免费模拟数据源；看日志；举手找讲师
监控面板不动行情未推进/刚启动等几分钟；确认执行任务仍在运行；重启任务一次
计划写不下去目标太大只写「每天 20 分钟」粒度的动作；第 1 周写满即达标
