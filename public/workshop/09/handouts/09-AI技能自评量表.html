AI 技能自评量表

开课前 5 分钟填 · 按真实频度打分 · 测完你就知道自己站在哪
开课首发放
总分填右边 → ____ / 50

评分标准：1 = 从未 · 2 = 偶尔（几月一次） · 3 = 有时（每月） · 4 = 经常（每周） · 5 = 每天。圈一个数字，凭第一直觉，别想太久。

第一部分 · 装（环境与工具）

1. 我知道量化交易大概是怎么回事（把买卖规则写成程序再检验）12345
2. 我在自己电脑上装过并跑通过开发工具（Docker / Python / Git 任一）12345
3. 遇到安装报错，我会看报错最后一行并动手搜解法，而不是直接放弃12345

第二部分 · 测（AI 辅助 + 回测）

4. 我用过 AI 助手帮我解释代码或写代码骨架（WorkBuddy 等都算）12345
5. 我能看懂一段简单 Python 代码在做什么（不用会写，看懂即可）12345
6. 我听说过回测，知道「历史表现好」不等于「未来也赚钱」12345

第三部分 · 跑（模拟盘与持续学习）

7. 我知道模拟盘（paper trading）和实盘的差别12345
8. 我能坚持一个 30 天的学习计划并留下记录（打卡/笔记都算）12345
9. 我清楚量化结果仅供学习研究、不构成投资建议，也从不拿生活必需钱去投资12345

第四部分 · 翻转（教会别人才算学会）

10. 我能给零基础的朋友讲清「量化流程五步：研究→写策略→回测→模拟→监控」12345
