讲师资控手册

11 月 · 时间待定
10 人 · 材料 08

一、课前 24 小时必做（关掉六个雷）

✓动作不做的后果
☐从零跑一遍：clone → Docker 启动 → AI 写策略 → 回测 → 模拟盘全链路，录屏留档演示卡壳，学员当场失去信任
☐确认官方 README 中文版当日状态（部署章节有无改版、命令有无变更），截图存演示脚本README 改版对不上，第 1 节双卡壳
☐备好备用镜像路径（本站 Gitea Loong/QuantDinger）并实测可达GitHub 现场抽风，全班 clone 卡死
☐预跑一套示例策略 + 回测结果截图（含收益曲线/指标），故障时投屏它有人环境起不来，整节空转
☐镜像预拉取：现场统一「先拉镜像再听讲」，讲课期间学员后台拉现场带宽被 10 台机器拉镜像打满
☐开场与收尾各念一遍合规口径：仅供学习研究、不构成投资建议、只用模拟盘与历史数据口径松动，课后有人拿真钱实操

一b、片源清单（R 环节 · 官方产品/解读视频）

节次片源（官方发布优先）时长看点（第二遍带问题看）离线✓
第 1 节 · 装QuantDinger 官方仓库/官网（www.quantdinger.com）产品介绍或 README 演示3–5′五模块界面长什么样；self-hosted 部署入口在哪☐
第 2 节 · 测官方回测/策略演示片段（无则用自己录屏替代）3–5′策略三件：入场/出场/仓位；报告页哪些指标先看☐
第 3 节 · 跑官方 Paper execution / Monitoring 演示（无则自己录屏）3–4′模拟盘与实盘的差别；监控面板三看：持仓/成交/权益☐

片源纪律：只放官方渠道或自录屏；不引第三方荐股/带单内容——合规红线。官方 Live App 站点未验证可达，一律禁引，演示只走本地部署。

二、时间轴资控（173′ 净时长 · 超时只砍讨论不砍交付）

时段环节讲师动作学员状态 · 卡点
0:00–0:15开场 15′自评量表（材料 09）→ 一句话立课：量化=把规则写清楚再用数据检验；念合规口径第一遍；宣布「先拉镜像」指令填表 · 认识三件交付物 · 后台开始拉镜像
0:15–1:00第 1 节 45′ · 装量化是什么（10′，五站链路图）→ 放片 → 投屏从零部署（20′，对齐 README 中文版步骤）→ 学员操作 + 组长巡查（15′）最大卡点：Docker 没装/起不来 → 甩备用镜像 + 预拉取
1:00–1:10茶歇 10′巡场补卡壳学员；确认过半学员 Web 界面已打开没起来的优先救
1:10–1:55第 2 节 45′ · 测AI 研究助手三问演示（10′）→ 策略骨架填入 + 语法检查（10′）→ 回测配置与运行（10′）→ 读报告写三行结论（15′）卡点：语法报错 → 贴回报错给 AI 改；空白面板 → 调小均线周期
1:55–2:30第 3 节 35′ · 跑模拟盘部署演示（8′）→ Monitoring 三看（7′）→ 30 天计划模板填写（15′）→ 念合规口径第二遍模拟盘起不来的看投屏演示版也算完成
2:30–2:40收尾 10′自检表（材料 06）→ 组长复核签字 → 互换测试（看别人的报告挑一个错）→ 合影发群三项全勾才走

三、学员卡点分级（SOP）

级别表现处置
绿 · 自助照手册排障表能解决让组长引导，讲师不动
黄 · 组长级报错看不懂、界面找不到模块组长拿手册排障表对照处理
红 · 讲师级Docker 起不来 / AI 助手无响应 / 连环报错讲师上门 ≤3 分钟；超时切备用演示环境跟做，课后补装
黑 · 弃环境15 分钟救不活明确告知：切投屏演示版跟做，三项交付物照样可勾（策略/报告用演示版截图 + 自己的三行结论）

四、交付物核验口径（收尾用）

交付物核验动作
① 环境+策略界面截图 + 策略无报错截图；口头问一句入场/出场/仓位
② 回测报告报告截图 + 三个数 + 三行结论（结论必须是自己的话）
③ 30 天计划三栏写满；抽一行问「这天 20 分钟你具体做什么」

五、合规与边界（每场必念两遍）

量化结果仅供学习研究，不构成投资建议；课堂只用模拟盘和历史数据，不碰真实资金。
不荐股、不带单、不展示实盘账户；学员问「买什么」一律引回「先回测」。
客户端场景只提 WorkBuddy；禁提其他客户端产品名。
外链只用 github.com/OpenByteInc/QuantDinger、www.quantdinger.com、/workshop/07/。
