课前准备清单

开课前一天发群 · 15 分钟准备，省现场 30 分钟（量化课装机最耗时）
QuantDinger 工作坊
11 月 · 时间待定

本课不需要量化或金融背景，会装软件、能复制粘贴就能跟。但 Docker 部署是现场最耗时的一步——课前装好 Docker，第 1 节你能省出一半时间写策略。

① 必带设备

一台笔记本电脑（必带，建议 8G 内存以上；手机没法跑 Docker）。
充电器（3 小时高强度使用）。
能上网的网络：现场 Wi-Fi 或手机热点（拉镜像很吃流量，建议 Wi-Fi）。

② 课前 15 分钟做三件事

✓动作做到什么程度
☐安装 Docker Desktop（Windows/Mac）或 docker-ce（Linux）终端敲 docker ps 不报错（会列出容器表头即算通过）
☐克隆仓库：git clone https://github.com/OpenByteInc/QuantDinger.git本地有 QuantDinger 目录；拉不动就换本站 Gitea 镜像 Loong/QuantDinger，实在不行现场再说
☐翻一遍官方中文 README知道它是开源 AI Trading OS（Apache-2.0），覆盖 crypto/股票/外汇，部署章节在哪一节

③ 装不上怎么办（提前排雷）

症状解法
Windows 装 Docker 要开虚拟化BIOS 开 VT-x；或先启用 WSL2 再装 Docker Desktop
Mac Apple 芯片装完打不开确认装的是 Apple Silicon 版；首次启动按提示授权
git 命令不存在装 git 或直接下载仓库 ZIP 解压也能用
以上都卡住没关系照样来——现场有备用演示环境跟做，课后再装
合规提前说：课堂全部量化结果仅供学习研究，不构成投资建议；只用模拟盘和历史数据，请勿带真实资金账户来。
