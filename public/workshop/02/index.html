开工前三件事 · 备好钥匙，查一遍家底

前两件各 10 分钟；第三件几分钟，确认第一期的 ima、公众号、工作流都还在跑

① GitHub 注册 + 领「钥匙」 1. 打开 github.com → Sign up：填邮箱、密码、用户名，去邮箱点验证链接；
2. 登录后右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic)；
3. Generate new token (classic) → 起个名字（如 chai）→ 勾选 repo → Generate；
4. 复制 ghp_ 开头的一串存好（只显示这一次）——这就是指令卡 ① 要交的「钥匙」。
卡住了？详细图文见 跟做手册第 1 节
② WorkBuddy 安装 + 注册 1. 打开 www.workbuddy.cn → 下载对应你电脑的版本，安装；
2. 首次打开，按提示注册并登录；
3. 新开一个对话——下面两张指令卡就粘在这里用。
③ 第一期家底体检 · ima / 公众号 / 工作流 1. ima：打开 ima.qq.com 扫码登录——知识库和素材还在；设置 → 开放 API 里的 Client ID / API Key 还在（忘了就在这页重置一份）；
2. 公众号：登录 mp.weixin.qq.com——草稿箱里第一期的素材和草稿还在；
3. 工作流：在 WorkBuddy 对话里说「跑一次第一期的工作流」——能出稿就是活的。哪一步断了别慌，带着问题来现场，讲师带你补。
第一期怎么配的忘了？见 第一期跟做手册

🔑 WorkBuddy 提示词 · 复制即用

两句话把网站搭起来。用法：复制 → 贴到 www.workbuddy.cn 对话框 → 把你领好的钥匙贴在冒号后面 → 发送。钥匙还没领？先看上方「开工前三件事」。换品牌、换自我介绍等进阶玩法，见 跟做手册 →

指令卡 ① · 交钥匙
复制github.com/kenyanghui/chaiAI，接入github classic repo tokens：
钥匙哪里拿：github.com → Settings → Developer settings → Tokens (classic)
指令卡 ② · 要一个同款网站
接下来改我的网站品牌、定位和我的自我介绍，并根据我的需求响应改网站设计
几分钟出网址：https://你的用户名.github.io/chaiAI

💡 出错统一动作：把报错原话发回给 WorkBuddy，说「请修好后继续」。
