三个"卡住"的瞬间

中了一条，这节课就是为你开的

名片困在微信里想给别人介绍自己，只能发一段微信自我介绍——没有一个是"打开就能看"的。
作品散落各处写过的东西、做过的案例，散在聊天记录和收藏里，想展示时一件都拿不出手。
网站想做做不动知道该有个网站，一听"要服务器、要备案、要找人做"，就放下了。

三节 · 三个交付物

不是听，是当场做出来、带走的

第 1 节 · 安 · 50′
GitHub 安家

免费托管、全球可访问。15 分钟五步上线：注册 → 建仓 → 写三段 → 开 Pages → 打开网址。

交付 ① 个人网站已上线（网址能打开）
第 2 节 · 跑 · 55′
workbuddy 自动产线

把"写内容"和"上网站"焊在一起：选内容 → 接源 → 运行预览，写完即发布，零道工序。

交付 ② 自动更新产线跑通（有截图）
第 3 节 · 阵地 · 40′
把网站长成阵地

栏目按"别人来想看什么"规划，30 天更新节律 + 复盘卡，让网站自己长大。

交付 ③ 30 天阵地计划（三栏写满）
