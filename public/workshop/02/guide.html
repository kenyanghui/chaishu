没看到怎么办：收不到验证邮件：检查垃圾箱；还不行换手机号验证注册

没看到怎么办：用户名不满意：先不改，不影响跟做；实在要改问 WorkBuddy「怎么改 GitHub 用户名」

2第 1 节 · 唯一的动手配置：领一把钥匙

本节目标：从 GitHub 领一串 ghp_ 开头的「钥匙」，以后你的 GitHub 全由持钥匙的 WorkBuddy 代管｜预计 10 分钟

动手前确认：已登录 GitHub（第 0 节）。
走进钥匙发放处（连点四下）
  • 钥匙的官方名叫 Personal access token（个人访问令牌）——不用记，你就当它是钥匙
  • 点右上角头像 → Settings（设置）
  • 左侧菜单拉到最底 → 点 Developer settings（开发者设置）
  • 点 Personal access tokens → Tokens (classic)
手机菜单项多，一定拉到最底才见 Developer settings；找不到就切桌面版网站
电脑左侧菜单最底部分组，一眼可见
检查点（看到才算做对）：打开了 Tokens (classic) 页面，右上角有个 Generate new token（生成新令牌）按钮
没看到怎么办：找不到 Developer settings：注意是从 头像 → Settings 进（不是仓库页的 Settings）；小屏幕菜单要展开
点 Generate new token (classic)
  • 点右上角 Generate new token → 选 Generate new token (classic)
  • 会打开一个填表页，只有三处要填，下一台告诉你怎么填
检查点（看到才算做对）：页面标题是 New personal access token (classic)
没看到怎么办：看到 fine-grained 字样选错了：退回去重选 classic 那个
填三处：名字、有效期、权限
  • Note（备注）填：workbuddy
  • Expiration（有效期）选 90 days（90 天）；怕到期麻烦可选 No expiration（不过期，安全性略低）
  • Select scopes（权限）只勾一个：找到 repo 这个词，勾它前面的框——意思是「这把钥匙能管理我的代码仓库」。子项会自动跟着勾上，不用管
检查点（看到才算做对）：Note 有字、Expiration 已选、repo 前面的框已打勾
没看到怎么办：子项勾不动：不用管，勾了 repo 大项就够
生成并立刻复制
  • 拉到页面最底点绿色 Generate token 按钮
  • 出现一串 ghp_ 开头、约 40 位的字符——点它旁边的复制图标
  • ⚠️ 只显示这一次！关掉页面就再也看不到（丢了就重新领一把，不心疼）
检查点（看到才算做对）：剪贴板/备忘录里有一串 ghp_ 开头的字符
没看到怎么办：手滑关了页面：回 Tokens (classic) 列表重新 Generate 一把，旧的自动作废
保管：钥匙三不原则
  • 存进手机备忘录（或密码管理器），标注「GitHub 钥匙」
  • 三不：不发微信群、不截图发任何地方、不告诉任何人（WorkBuddy 除外）
  • 它等于你网站的钥匙，泄露了别人就能改你的站
检查点（看到才算做对）：钥匙已存好，且知道它不能给谁看
没看到怎么办：怀疑泄露（比如发错群）：回 Tokens (classic) 页面对着这把钥匙点 Delete（删除），它瞬间作废，再领一把新的

本节排障表（4 个常见卡点）

症状可能原因解法
Generate 按钮点不动没填备注或没勾权限回第 3 步补齐：Note 填字 + repo 打勾
钥匙找不到了只显示一次是安全设计重新领一把；把新的交给 WorkBuddy 时说「换用这把新钥匙」
90 天后过期了有效期到了重走本节领新钥匙，发给 WorkBuddy 说「换用这把新钥匙」
想收回 WorkBuddy 的权限课程结束想断开Tokens (classic) → 对应钥匙 → Delete；WorkBuddy 立刻失去操作权

3第 2 节 · 两句话，让网站上线

本节目标：把钥匙交给 WorkBuddy，再说一句「把讲师站变成我的网站」——网址到手｜预计 20 分钟（含等待）

动手前确认：第 1 节的 ghp_ 钥匙在手；WorkBuddy 已登录。
指令①：交钥匙
  • 把下面这段话复制给 WorkBuddy（把 ghp_xxx 换成你那串）：
  • 「这是我的 GitHub 个人访问令牌（classic，repo 权限）：ghp_xxx。请保存为我的 GitHub 凭据，之后你替我操作 GitHub（复制仓库、提交修改、查状态）都用它。回复里不要展示令牌原文。」
  • 发送
检查点（看到才算做对）：WorkBuddy 答复已保存/已配置，且没有把钥匙原文复述出来
没看到怎么办：它说不会保存：换说法「把这串令牌记作我的 GitHub 凭据，后续操作 GitHub 都带上它」；再不行去 WorkBuddy 的设置/连接器入口找 GitHub 手动粘贴
指令②：要一个同款网站
  • 把下面这段话发给 WorkBuddy（把「我的用户名」换成你的）：
  • 「请把讲师的网站仓库 github.com/kenyanghui/chaiAI 复制一份到我的 GitHub（用户名：我的用户名）名下，做好让它变成公开网站所需的全部设置和首次构建。全部弄好、网站能访问之后，把我的网站网址告诉我。」
  • 发送。剩下的是它的事：复制、开通、构建，一般几分钟。你不用懂它在干什么
检查点（看到才算做对）：WorkBuddy 回复你一个网址：https://你的用户名.github.io/chaiAI
没看到怎么办：它中途停了：发「继续」；它报错：把报错原话发回，「这是报错，请修复后继续」——AI 出错 AI 修，这是本路线的精髓
亲眼验收
  • 浏览器新开标签页，输入 WorkBuddy 给你的网址（用户名全小写、斜杠别漏）
  • 首次访问可能要等几分钟
  • 看到和 chai.aibay.asia 同款首页 = 上线成功
检查点（看到才算做对）：浏览器显示讲师站同款页面，地址是你的用户名.github.io/chaiAI
没看到怎么办：404：先等 5 分钟强刷（Ctrl+Shift+R）；还不行把排障表第一句发给 WorkBuddy

本节排障表（4 个常见卡点）

症状可能原因解法
网站 404 打不开还没就绪发给 WorkBuddy：「我的网站 ____ 打不开。请检查我的 chaiAI 仓库：网站功能是否已正确开通、最近一次自动构建是否成功完成，有问题就修复并重新构建，完成后告诉我。」
WorkBuddy 说钥匙无效钥匙复制缺了字符/已过期回第 1 节重新领一把完整的，重发指令①
WorkBuddy 干到一半停了长任务分段/当日额度发「继续」；再停就把剩下的事拆成一句新指令
网站过几天突然打不开构建出问题发给 WorkBuddy：「我的网站 ____ 打不开了，请检查并修复到能访问，然后告诉我原因。」

4第 3 节 · 换装：说清楚你是谁

本节目标：想好你的三段话，两条指令发出去，站名、介绍、联系方式全换成你的｜预计 30 分钟

动手前确认：你的网站已能打开（第 2 节）。
想好三段话（5 分钟，写在手机备忘录）
  • ① 我是谁：一句话身份 + 1–2 个标签（如：拆书家 / 顾问 / 设计师）
  • ② 我做什么：作品、服务、案例，2–3 条，每条一句话
  • ③ 怎么找到我：微信 / 邮箱 / 公众号名
  • 再想一个品牌名（显示在站名位置，如「阿珍的小站」）
检查点（看到才算做对）：备忘录里三段话 + 一个品牌名
没看到怎么办：写不出来：先照讲师站的格式仿写，回头再改——先跑通再完美
指令③：换品牌
  • 把下面这段话发给 WorkBuddy（括号换成你的内容）：
  • 「请把我的网站（GitHub 用户名：我的用户名，仓库名 chaiAI）整体换成我的品牌：站名改为（你的品牌名），浏览器标签页标题改为（你的名字 — 一句话定位）。改完提交并等网站更新完成再告诉我。」
  • 发送，等几分钟，强刷网站验收
检查点（看到才算做对）：浏览器标签标题、站内名字都显示你的品牌
没看到怎么办：网站白屏/打不开（它改坏了）：发「网站坏了，请恢复到上一个能用的版本，然后换一种更稳的方式重改，只改文字内容」——AI 改坏 AI 修，比手改安全
指令④：换自我介绍
  • 把下面这段话发给 WorkBuddy：
  • 「请把我网站『关于』页的自我介绍换成我下面三段话：①我是谁____；②我做什么____；③怎么找到我____。联系方式也换成我的。改完提交并等网站更新完成再告诉我。」
  • 发送，等几分钟，打开「关于」页验收
检查点（看到才算做对）：「关于」页显示你的三段话和你的联系方式
没看到怎么办：白屏：同上发恢复指令；重改时只让它动文字
把指令包存好
  • 把本手册的 4 条指令（①交钥匙 ②要网站 ③换品牌 ④换介绍）连同你的填空版，存进手机备忘录或 ima 库
  • 以后每次改站：说清楚你要什么就行——指令包就是你的范本
检查点（看到才算做对）：备忘录里有一份填好空的指令包
没看到怎么办：指令丢了：回本手册页重新复制；或问 WorkBuddy「把我仓库最近的改动列出来」倒推

本节排障表（4 个常见卡点）

症状可能原因解法
改完网站白屏AI 改坏了内容发「恢复到上一个能用的版本，再用更稳的方式重改」——这是本路线最大的优点：改坏了一句话就能救回
WorkBuddy 找不到我的网站用户名/仓库名报错指令里带全：GitHub 用户名 + 仓库名 chaiAI；复制网址给它最保险

5第 4 节 · （进阶选学）装 rsi 工作流，一条产线两个出口

本节目标：给 WorkBuddy 装上「rsi 工作流」技能包——所有工程细节从这步起全部包进技能里：素材 → 你的网站 + 公众号草稿箱｜预计 40 分钟

动手前确认：电脑 + WorkBuddy 已能操作你的网站（第 2 节）+（可选）ima 已装、公众号后台能进。手机用户建议跳过本节，直接去 30 天计划。
装 rsi 技能包（60 秒，本期唯一要动手装的东西）
  • 浏览器打开：github.com/kenyanghui/rsi-ima-workbuddy-wechat-web
  • 绿色 Code 按钮 → Download ZIP（下载压缩包）→ 解压
  • 解压出的文件夹改名为 rsi-ima-workbuddy-wechat-web（去掉结尾的 -main）
  • 整个文件夹放进你电脑的 ~/.workbuddy/skills/ 文件夹（没有就新建一个叫 skills 的），重启 WorkBuddy
  • 装上它，WorkBuddy 就懂了这套站的所有内部构造——你在对话里只管说人话
Windows文件管理器地址栏输入 %USERPROFILE%\.workbuddy\skills 回车直达
MacFinder 按 Cmd+Shift+G 输入 ~/.workbuddy/skills 前往；没有 skills 文件夹就新建再放
检查点（看到才算做对）：对 WorkBuddy 说「网站体检」，它能回报你网站的健康状况即装好
没看到怎么办：没反应：确认重启过 WorkBuddy；文件夹名没带 -main；放在 skills 文件夹里面而不是旁边
跑一次一源双出口
  • 从 ima 库（ima.qq.com 或 App）挑一个你熟悉、有素材的主题
  • 对 WorkBuddy 说：「用我提供的素材写一篇公众号文章初稿，初稿先给我看」——取 2–3 份素材给它
  • 人工校对一遍再放行——你负责把关，机器不负责
  • 校对后说：「发到我的网站，并同步一份到我的公众号草稿箱」——网站多一篇文章 + 草稿箱躺着同一篇，群发与否你课后自己定
检查点（看到才算做对）：两张截图：你的网站多了新文章 + 公众号草稿箱（mp.weixin.qq.com 后台）躺着同一篇
没看到怎么办：公众号出口失败：让 WorkBuddy「检查公众号草稿箱功能需要开通什么权限，把步骤告诉我」；ima 取不到素材：检查库是否已导入资料

时间做什么怎么自查没掉队
