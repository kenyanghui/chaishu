1第 0 节 · 20 分钟补底盘

本节目标：把 GitHub 账号准备好，认识我们要拆的站｜预计 20 分钟

动手前确认：手机或电脑浏览器能正常上网，能收到短信或邮件验证码。
注册 GitHub 账号（已有就登录，跳到第 2 步）
  • 浏览器打开 github.com，点右上角 Sign up
  • 邮箱建议用 QQ 邮箱/163 邮箱即可；密码记在手机备忘录里
  • 收验证码（邮箱收不到就换手机号验证），按提示完成
手机建议横屏操作；页面底部可切「Desktop version」找按钮
电脑直接按提示点即可
检查点（看到才算做对）：右上角出现你的用户名头像，就是登录成功了
没看到怎么办：收不到验证邮件：检查垃圾箱；还不行换手机号验证注册。用户名提示被占用：换一个，用户名会出现在你的网站网址里，选个好记的
看一眼你要拆的站和源仓
  • 讲师站：chai.aibay.asia —— 你等下就拥有同款
  • 源仓库：github.com/kenyanghui/chaiAI —— 点进去随便逛逛，能看到一堆文件夹和文件就是它
检查点（看到才算做对）：两个网址都能打开；源仓页面右上角能看到 Star 和 Fork 按钮
没看到怎么办：Fork 按钮没看到 = 没登录，回第 1 步

本节排障表（3 个常见卡点）

症状可能原因解法
注册页面转圈打不开网络波动刷新重试；手机切 4G/5G 再试
验证码一直收不到邮箱拦截或输错邮箱换手机号验证；或注册 QQ 邮箱重来
用户名不知道填什么用户名 = 网站网址的一部分选英文、好记、和你的名字/品牌相关，如 zhangsan-dev

2第 1 节 · GitHub 安家：fork 讲师站

本节目标：把讲师站的完整源码复制一份到你的 GitHub 账号下｜预计 15 分钟

动手前确认：已登录 GitHub（第 0 节）。
打开讲师源仓并点 Fork
  • 浏览器打开：github.com/kenyanghui/chaiAI
  • 点右上角灰色 Fork 按钮 → 进入 fork 页面
  • 什么都不用改，直接点绿色 Create fork 按钮
检查点（看到才算做对）：页面跳转到 你的用户名/chaiAI 仓库，顶部写着 forked from kenyanghui/chaiAI，文件列表和讲师站一模一样
没看到怎么办：没有 Fork 按钮：你没登录；点了没反应：刷新重试；提示错误：等 2 分钟再点（GitHub 偶发抽风）
确认你的仓库名
  • 你的仓库地址应该是 github.com/你的用户名/chaiAI
  • 把这一行网址复制存到手机备忘录，后面要用
检查点（看到才算做对）：地址栏里是你的用户名 + /chaiAI
没看到怎么办：仓库名不是 chaiAI（fork 时手滑改了）：Settings → General → Repository name 改回 chaiAI

症状可能原因解法
Fork 后仓库是空的fork 没完成就关了页面回讲师仓重点一次 Fork，等页面完整跳转
仓库里没有 src 文件夹fork 错了仓库确认地址是 kenyanghui/chaiAI，不是别的仓
手机上 Fork 按钮找不到手机版页面折叠了页面拉到 Code 标签上方按钮区，或切桌面版网站

3第 2 节 · 让你的网站上线

本节目标：开通 GitHub Pages，拿到 https://你的用户名.github.io/chaiAI 这个网址｜预计 20 分钟（含等待）

动手前确认：第 1 节完成，你的 /chaiAI 仓库能打开。
启用 fork 仓库的 Actions（自动构建开关）
  • 在你的 chaiAI 仓库页面上方点 Actions 标签
  • 页面会显示黄色提示条 I understand my workflows, go ahead and enable them —— 点它
  • 等页面出现 deploy / Pages 相关工作流名称即可，暂时不用管它们
检查点（看到才算做对）：Actions 页不再显示黄色提示条，左边栏能看到工作流列表
没看到怎么办：没有黄色提示条：可能已默认启用，直接下一步
把 Pages 的构建方式设为 GitHub Actions
  • 仓库页面上方点 Settings（设置）
  • 左侧菜单找到 Pages（页面）
  • Build and deployment 下面的 Source 下拉框，选 GitHub Actions（不是 Deploy from a branch）
  • 不用填别的，离开页面即自动保存
检查点（看到才算做对）：Source 显示 GitHub Actions；下方不再让你选分支
没看到怎么办：左侧找不到 Pages：Settings 菜单在小屏幕上要展开 Code and automation 分组才看得到
触发第一次构建：随便改一个字提交
  • 回仓库主页点 README.md 文件 → 右上角铅笔图标进入编辑
  • 在正文最后敲一个空格再删掉（内容可以不变），点右上角 Commit changes → 绿色按钮确认
  • 点 Actions 标签，能看到一条新的工作流在跑（黄点转圈）
  • 等 1–5 分钟，黄点变绿勾
检查点（看到才算做对）：Actions 里最新一条记录前面是绿色对勾
没看到怎么办：红叉：点进那条记录看日志第一段红字，通常是网络抽风，等 2 分钟回 README 再提交一次空改动重跑
打开你的网站
  • 浏览器新开标签页，输入：https://你的用户名.github.io/chaiAI
  • 注意用户名全小写、斜杠别漏；首次访问要等 1–10 分钟
  • 看到和小蛮腰·拆AI 一样的首页 = 成功
检查点（看到才算做对）：浏览器显示讲师站同款页面，地址是你的用户名.github.io/chaiAI
没看到怎么办：404：等 10 分钟再强刷（电脑 Ctrl+Shift+R / 手机清缓存重开）；还 404 回查第 2 步 Source 是否选了 GitHub Actions、第 3 步是否绿勾

本节排障表（5 个常见卡点）

症状可能原因解法
网站 404构建没完成 / Pages 方式选错 / 网址打错按第 4 步的排查顺序走一遍；网址严格小写
Actions 一直黄点不结束首次构建偶发排队等 10 分钟；取消重跑：点进工作流 → Cancel → 重新提交空改动
Actions 红叉文件在 fork 后损坏（极少）点进日志看第一行红字截图；回 README 提交空改动重试两次；仍红叉带截图进微信群问
改了内容网站没变化浏览器缓存 / 构建还在跑电脑 Ctrl+Shift+R 强刷；手机换浏览器试；Actions 绿勾后再看
网址打不开但 Actions 绿勾Pages 未生效回 Settings → Pages 看是否显示 Your site is published；没有则重做第 2 步

4第 3 节 · 换装：把站变成你的

本节目标：改 3 个文件，把站名、品牌、自我介绍换成你的——不需要装任何软件｜预计 40 分钟

动手前确认：你的网站已能打开（第 2 节）。
想好三段话（5 分钟，写在手机备忘录）
  • ① 我是谁：一句话身份 + 1–2 个标签（如：拆书家 / 顾问 / 设计师）
  • ② 我做什么：作品、服务、案例，2–3 条，每条一句话
  • ③ 怎么找到我：微信 / 邮箱 / 公众号名
检查点（看到才算做对）：备忘录里三段话写完
没看到怎么办：写不出来：先抄讲师站的格式，回头再改——先跑通再完美
改浏览器标签页标题（index.html）
  • 仓库主页点 index.html → 铅笔编辑 → Ctrl+F（手机浏览器菜单里找「查找」）搜「小蛮腰」
  • 把「小蛮腰·拆AI — 工作坊课程阵地 | 拆的是 AI，拆为己用」改成「你的名 — 一句话定位」
  • Commit changes 提交
检查点（看到才算做对）：提交后等 2 分钟（Actions 绿勾），打开你的网站，浏览器标签页标题变成你的名字
没看到怎么办：标题没变：强刷；确认改的是你自己仓库（地址栏是你的用户名）不是讲师的
改站内品牌名（Navbar 和 Footer）
  • 点进 src/components/Navbar.jsx → 铅笔 → 搜「小蛮腰·拆AI」→ 改成你的品牌名 → 提交
  • 同样改 src/components/Footer.jsx 里的「小蛮腰·拆AI」
  • 这两处分别是页面顶部导航和底部的名字
检查点（看到才算做对）：等构建完强刷网站，页面左上角和底部都显示你的品牌名
没看到怎么办：页面报错打不开：说明改坏了标点（把引号或分号删了）。回该文件编辑页，用History（历史）按钮找到你提交前的那版，一键恢复
改自我介绍页（About.jsx）
  • 点进 src/pages/About.jsx → 铅笔编辑
  • 只改中文文案文字：把讲师的介绍替换成你第 1 步写的三段话；别动英文单词、尖括号 < > 和大括号 { } 里的结构
  • 改多少看精力：至少改掉「关于」页里最显眼的一段自我介绍和联系方式
  • 提交后等构建、强刷验证
检查点（看到才算做对）：网站「关于」页显示你的自我介绍和你的微信/公众号
没看到怎么办：改完页面白屏：动了代码结构。用文件 History 恢复上一版，重来一次，这次只改引号里面的中文
（可选）改工作坊数据
  • src/data/workshops.js 是六场工作坊的文案数据：日期、标题、简介
  • 想换成你自己活动信息再动；看不懂就先不动，不影响其他功能
检查点（看到才算做对）：改完网站「工作坊」页信息更新
没看到怎么办：页面乱了：同上用 History 恢复

症状可能原因解法
提交后网站白屏/报错改坏了代码结构（删了引号/括号）进该文件 → History（历史）→ 找红色提交前版本 → 恢复；再改一次，只动中文文案
搜「小蛮腰」搜不到标点全半角不同改搜「拆AI」或直接肉眼找到那行

5第 4 节 · （进阶选学）WorkBuddy 自动产线

本节目标：装上 rsi 技能，让 WorkBuddy 替你改站、发文章：素材 → 你的网站 + 公众号草稿箱｜预计 40 分钟

动手前确认：电脑 + 已登录 www.workbuddy.cn + 已登录 GitHub + （可选）ima 已装、公众号后台能进。手机用户建议跳过本节，直接去 30 天计划。
装 rsi 技能（60 秒）
  • 浏览器打开：github.com/kenyanghui/rsi-ima-workbuddy-wechat-web
  • 绿色 Code 按钮 → Download ZIP → 解压
  • 解压出的文件夹改名为 rsi-ima-workbuddy-wechat-web（去掉 -main）
  • 整个文件夹放进你电脑的 ~/.workbuddy/skills/ 目录（没有就新建）
  • 重启 WorkBuddy
Windows~ 即 C:\Users\你的用户名\；在文件管理器地址栏输入 %USERPROFILE%\.workbuddy\skills 回车直达
MacFinder 按 Cmd+Shift+G，输入 ~/.workbuddy/skills 前往；没有该文件夹就新建 skills 再放
检查点（看到才算做对）：对 WorkBuddy 说「网站体检」，回复列表里有 rsi-ima-workbuddy-wechat-web 即装好
没看到怎么办：说没反应：确认重启过 WorkBuddy；确认文件夹名没带 -main 后缀；确认放在 skills 目录里面而不是旁边
克隆你的 fork 并换装
  • 对 WorkBuddy 说「clone 我的 fork」，它会帮你把 你的用户名/chaiAI 拉到本地
  • 说「把站换成我的」，把站名/署名/一句话简介报给它——它只改数据文件，骨架不动
  • 说「推回我的 fork」——改动自动提交回 GitHub，Actions 自动构建
检查点（看到才算做对）：等 2 分钟强刷你的网站，改动已生效
没看到怎么办：clone 失败：检查 WorkBuddy 是否已登录你的 GitHub 授权；推回失败：让 WorkBuddy 把报错原文贴出来，带截图进群问
跑一次一源双出口
  • 从 ima 库（ima.qq.com 或 App）挑一个你熟悉、有素材的主题
  • 取 2–3 份素材喂给 WorkBuddy，生成一篇初稿，人工校对一遍——你负责把关，机器不负责
  • 出口 A：成稿进你的网站仓库，网站多一篇文章
  • 出口 B：进你的公众号草稿箱（mp.weixin.qq.com 后台可见），群发与否你课后自己定
检查点（看到才算做对）：两张截图：你的网站上多了新文章 + 公众号草稿箱躺着同一篇
没看到怎么办：公众号出口失败：确认已在公众号后台开通草稿箱接口权限（设置与开发→API）；ima 取不到素材：检查库是否已导入资料

续30 天巩固计划（自助版）

工作坊的成果 30 天不用就会忘。每周一小步，周末 5 分钟自查没掉队。

时间做什么怎么自查没掉队
第 1 周上线周：完成第 1–3 节；把网址发给 3 个朋友，让他们告诉你第一眼看懂你是谁吗网站能打开 + 朋友能说出你的一句话定位
第 2 周换装周：About 页写满你的内容；发第一篇（哪怕只有 200 字）文章到网站网站内容 ≥ 1 篇属于你的文章
第 3 周产线周（进阶）：装技能，跑通一次 ima → 网站/草稿箱草稿箱里躺着自动产出的初稿
第 4 周飞轮周：定一个日更/周更节奏；周末花 5 分钟回看本月产出，删掉不想要的，定下月主题本月产出清单 ≥ 4 条，且写下了月主题
卡住怎么办（按顺序试）
1. 重读当前步骤的「检查点」和本节排障表——90% 的卡点都在里面；
2. 把你看到的界面截图保存下来，对照排障表找「症状」一栏；
3. 还不行：带上截图来微信群问，微信 ikoning365（点击不了就手动复制添加）。
