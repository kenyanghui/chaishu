本课不需要预习任何知识，也不需要会写代码，但需要你带上"原料"——工具课不预热，现场就会把时间花在找素材上。

① 必带设备

一台笔记本电脑（强烈建议，第 2 节接产线手机端基本没法做）。
充电器 / 充电宝（3 小时高强度使用，掉电很快）。
能上网的流量或确认现场 Wi-Fi 可连。

② 必带"原料"（三段 + 一篇）

首页三段素材，放进一个文档，现场直接粘贴：

我是谁：一句话身份（拆书家 / 顾问 / 设计师 / 宝妈……都行）
我做什么：作品 / 服务 / 案例，2–3 条，每条一句话
怎么找到我：微信 / 邮箱 / 公众号名
一篇写熟的内容：任何你写过、讲过、发过的完整内容（第 2 节产线用它跑）

实在没想好：现场写三句话也够——先上线，再完善。

③ 两大底盘提前做好（10 分钟，新学员必做）

第一期升级承接：ima 知识库是「库」，公众号是「号」。这两样课前配好，现场直接进正题。

✓底盘五步 / 四步
☐ima
五步		下载登录 → 新建知识库（命名带自己名字）→ 建 2 个分类 → 导入 3 份素材 → 截图。
☐公众号
四步		确认有号（个人订阅号即可）→ 登录 mp.weixin.qq.com → 设置与开发 → 基本配置 → 记录 AppID（不必现场填 AppSecret）。

分流说明：上过第一期、库和接口都已配好的，跳过本节，做进阶项：把网站首页文案存进库 + 用公众号发一条「我要开个网站」。

兜底话术：没配好不影响上课；第 0 节 20 分钟现场补齐。

课前自检 3 问：库建好了吗 ☐　3 份素材进了吗 ☐　公众号能登录吗 ☐
